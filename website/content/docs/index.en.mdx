## In one line

**BORA** locks Dataset config, runs bounded Attempts, projects what the agent can see, and lets an **independent evaluator** own the score.

Many agent benchmarks score the model and leave harness concerns—orchestration, isolation, visibility, evaluation barriers—to private stacks. Swap the coding agent or isolation mode and scores stop lining up. BORA is that outer boundary.

## What you can do

- Run examples or your own Dataset with `bora lock` / `bora run`
- Switch Codex / Claude / Pi / OpenCode via **ACP** without a per-vendor scraper in Core
- Browse local suite runs and trajectories with `bora view`
- Optionally upload results to the Registry and browse them in Hub
