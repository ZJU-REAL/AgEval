Agent evaluation often focuses on model scores while orchestration, visibility, and scoring authority stay in vendor-specific stacks. Changing the coding agent or execution environment makes results and trajectories hard to compare.

**BORA** (Bounded Orchestration for Runtime Agents) provides that outer boundary: lock Dataset configuration, run a bounded Attempt, control visibility, and let an **independent evaluator** produce the result. Trajectories support inspection and analysis; they are **not** scoring authority.
