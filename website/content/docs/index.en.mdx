---

Agent evaluation often focuses on model scores while orchestration, visibility, and scoring authority stay in vendor stacks. Changing the coding agent or the box makes results hard to compare.

**ageval** (agent eval) is that outer boundary: lock a dataset, run a bounded Attempt in a chosen box, control visibility, and let an **independent evaluator** produce the result. Trajectories support inspection; they are **not** scoring authority.

The CLI and packages are `ageval`. The delivery unit is a dataset, not SQL.
