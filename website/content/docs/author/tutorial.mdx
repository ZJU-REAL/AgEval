---
title: Task 编写教程
description: 从 examples/datasets/minimal-demo 抄一题，改 run.py 与评测并跑通。
---

目标：本机能 lock、能 run、能出评测结果。

## 1. 复制最小结构

[`examples/datasets/minimal-demo`](https://github.com/ZJU-REAL/ageval/tree/main/examples/datasets/minimal-demo) 已是完整 dataset。复制一个 `tasks/<id>/`（可从 `terminal-jsonl-agg` 起步），目录名必须等于 `task_id`。

```text
tasks/hello/
├── task.yaml
├── run.py
└── evaluator.py
```

## 2. `task.yaml`

```yaml
format: ageval.task/1
task_id: hello
parameters:
  instruction: "Reply DONE"
agent_profiles:
  - id: solver
limits:
  wall_time_seconds: 300
  agent_invocations: 1
artifacts:
  publishable:
    - id: reply
      path: artifacts/reply.json
evaluation:
  inputs:
    - artifact: reply
      target: artifacts/reply.json
```

不要写 `harness:`、`provider:`、`assurance`。环境和 ACP entry 在根上 `profiles.yaml`。

## 3. 跑

```bash
uv run ageval lock examples/datasets/minimal-demo --task hello
uv run ageval run  examples/datasets/minimal-demo --task hello
```

ACP 缺 entry：先 `ageval executors -v`。详见 [ACP Profiles](/docs/agents/acp-profiles)。

评测默认是脚本比对 gold。若要用 LLM-as-judge，在同一份 `profiles.yaml` 加角色，gold 进环境后再 `Agent.session`；多只打分镜像（不同安装内容、顺序 stage）见 [编写 Evaluator](/docs/author/write-evaluator) 的「多 stage 打分 Host」。
