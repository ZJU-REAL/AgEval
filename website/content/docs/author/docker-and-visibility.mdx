## local 还是 docker

盒子写在 **`profiles.yaml`**，不是 `task.yaml` 的 `provider.kind`：

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: docker    # 或 local / e2b / ssh
```

| kind | 适合 |
| --- | --- |
| `local` | 开发、多数 example |
| `docker` | 需要容器边界 |
| `e2b` / `ssh` | 云上盒子；缺钥 `--probe` 失败 |

选 `docker`（或 `e2b`）时，成员下应有 **`environment/Dockerfile`**（或 image 选项），否则 lock 失败。docker 与 e2b 用同一份配方。

## 谁看得见什么

| 目录 | 谁用 |
| --- | --- |
| `prompts/`、`data/` 等 | 业务 / 可能进 agent 视野 |
| `evaluation/` | 只给评测（evaluate 相位才 upload） |
| `environment/` | Dockerfile、`setup.sh` |

真隔离靠 **不 mount + 评测前 upload**，不是靠删配置字段。这不是 `path_views`。

多 actor topology、镜像 bake-in 见 [盒子](/docs/agents/environments)。
