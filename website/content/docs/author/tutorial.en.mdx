---
title: Task authoring tutorial
description: Copy a task from examples/journeys, edit run.py and the evaluator, run it.
---

Goal: lock, run, and get an evaluation result on this machine.

Copy a `tasks/<id>/` directory from [`examples/journeys`](https://github.com/ZJU-REAL/ageval/tree/main/examples/journeys) (start from `terminal-jsonl-agg`). The directory name must equal `task_id`.

```yaml
format: ageval.task/1
task_id: hello
parameters:
  instruction: "Reply DONE"
agent_profiles:
  - id: solver
limits:
  wall_time_seconds: 300
  agent_invocations: 1
artifacts:
  publishable:
    - id: reply
      path: artifacts/reply.json
evaluation:
  inputs:
    - artifact: reply
      target: artifacts/reply.json
```

Do not write `harness:`, `provider:`, or `assurance`. The environment and ACP entry live in `profiles.yaml`.

```bash
uv run ageval lock examples/journeys --task hello
uv run ageval run  examples/journeys --task hello
```
