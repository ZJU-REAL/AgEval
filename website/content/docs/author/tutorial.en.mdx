title: Task authoring tutorial
description: Copy from examples/core, change harness and eval, run it.
---

Goal: a task that locks, runs, and produces an evaluation result. You don’t need the full field encyclopedia first.

## 1. Start from an example

[`examples/core`](https://github.com/ZJU-REAL/BORA/tree/main/examples/core) is a full Dataset. Either edit a task in place or copy `tasks/<id>/` and rename **both** the directory and `task_id`.

Minimal member:

```text
tasks/hello/
├── task.yaml
├── harness.py
└── evaluator.py
```

## 2. Skeleton `task.yaml`

```yaml
format: bora.task/1
task_id: hello

harness:
  runtime: python
  entrypoint: harness:run

parameters:
  active_profile: main
  harness_timeout_seconds: 300

provider:
  kind: local
  assurance: l0

agent_profiles:
  - id: main

limits:
  wall_time_seconds: 300
  agent_invocations: 2
  environment_actions: 0

artifacts:
  publishable:
    - id: session-output
      producer: harness
      path: artifacts/session-output.json
      media_type: application/json

evaluation:
  runtime: python
  entrypoint: evaluator:evaluate
  network: none
  inputs:
    - artifact: session-output
      target: artifacts/session-output.json
  output:
    format: json
```

No agent? Use `agent_profiles: []` and `agent_invocations: 0`.

## 3. Lock, then run

```bash
uv run bora lock <dataset> --task hello
uv run bora run <dataset> --task hello
```
