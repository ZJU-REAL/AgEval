title: Task authoring tutorial
description: Copy a task from examples/datasets/minimal-demo, edit run.py and the evaluator, run it.
---

Goal: lock, run, and get an evaluation result on this machine.

Copy a `tasks/<id>/` directory from [`examples/datasets/minimal-demo`](https://github.com/ZJU-REAL/AgEval/tree/main/examples/datasets/minimal-demo) (start from `terminal-jsonl-agg`). The directory name must equal `task_id`.

```yaml
format: ageval.task/1
task_id: hello
parameters:
  instruction: "Reply DONE"
agent_profiles:
  - id: solver
limits:
  wall_time_seconds: 300
  agent_invocations: 1
artifacts:
  publishable:
    - id: reply
      path: artifacts/reply.json
evaluation:
  inputs:
    - artifact: reply
      target: artifacts/reply.json
```

Do not write `harness:`, `provider:`, or `assurance`. The environment and ACP entry live in `profiles.yaml`.

```bash
uv run ageval lock examples/datasets/minimal-demo --task hello
uv run ageval run  examples/datasets/minimal-demo --task hello
```

Scoring defaults to a script against gold. For LLM-as-judge, add a role on the same `profiles.yaml` and `Agent.session` after gold lands. Several scoring images (different closures, sequential stages) are under [Write an evaluator](/docs/author/write-evaluator) → Named scoring hosts.
