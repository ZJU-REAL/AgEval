---
title: 编写 Evaluator
description: 独立打分；evaluation 块与 artifacts 怎么接。
---

Evaluator 只负责**算法与真值**，不启 agent、不持宿主密钥。PASS/FAIL 只能从这里来（再写进 Result）。

## `task.yaml` 片段

```yaml
artifacts:
  publishable:
    - id: session-output
      producer: run
      path: artifacts/session-output.json
      media_type: application/json

evaluation:
  runtime: python
  entrypoint: evaluator:evaluate
  network: none
  # tmpfs_mb: 256   # 可选；环境内 evaluator /tmp（MiB），省略则 32。不是 limits.*
  inputs:
    - artifact: session-output
      target: artifacts/session-output.json
    # gold 示例：
    # - package_path: evaluation/gold.json
    #   target: gold.json
  output:
    format: json
```

| 点 | 说明 |
| --- | --- |
| 屏障 | `run.py` 结束后才 materialize 输入 |
| gold | 放 `evaluation/`，evaluate 相位才 upload |
| artifact id | 必须和 `run.py` 实际写出的文件对上 |
| `tmpfs_mb` | 只改环境内 evaluator `/tmp`；省略 32 MiB。大 snapshot 在 **task** 上声明，不要写进 `limits` |

`evaluator.py` 由独占槽 `evaluation_runtime` 的默认赢家在 **parent 子进程**里跑（与 `run.py` 同一形态），不是再 `host.exec` 进盒子。PASS 仍只经引擎 bind。读结果时 runtime 与 evaluation 是分开的事实。job 可写 `evaluate_host.isolated: true`（Current：docker）另起打分盒；gold 只上打分 Host。见 [结果与 PASS](/docs/reference/results-and-pass)、[环境](/docs/agents/environments)。

## 两种评测

缺省是**确定性脚本**：读产物和 `evaluation/` 里的 gold，返回 `{status, score, metrics}`。不必调 Agent。没有 `evaluation/observation.jsonl`，Verifier 仍是 `result.json` 与文件树。

可选 **LLM-as-judge**：同一份 job `profiles.yaml` 再写一个角色（如 `judge`），`task.yaml` 的 `agent_profiles` 列入同一 id。gold **已经** upload 之后，`evaluator.py` 可以 `Agent.session("judge").invoke(...)`。提示词归题包。`invoke` 不得改 `profile_id` / executor。

```python
def evaluate(inputs):
    # inputs["agent"] 在本机盒子上会注入（parent socket）；没有就走脚本路径
    ...
    return {"status": "PASS", "score": 1.0, "metrics": {}}
```

约束：

| 点 | 说明 |
| --- | --- |
| PASS | 仍只看这次返回值；judge 文本 / `observation.jsonl` 不是分数 |
| 轨迹 | evaluate 相位的步写入 `evaluation/observation.jsonl`（省略 `user` 行，避免 gold 进 evidence）。不并进根 `trajectory.jsonl` |
| 调用预算 | `limits.agent_invocations` 要覆盖 solver **和** judge |
| 盒子 | SDK session 走 parent 的 Unix socket。ACP `attach_stdio` 打 **打分 Host**（缺省 = run 盒；job `evaluate_host.isolated: true` 时是 docker 第二实例）。不要把 Agent Service socket bind-mount 进容器 |

不调 `Agent.session` = 今日脚本路径。Verifier 有 observation 时复用 Trajectory 那种步骤卡片；没有则保持文件树。见 [本地 Viewer](/docs/run/local-viewer)。
