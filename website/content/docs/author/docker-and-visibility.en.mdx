## local vs docker

The box is on **`profiles.yaml`**, not `provider.kind` on the task:

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: docker    # or local / e2b / ssh
```

| kind | Fit |
| --- | --- |
| `local` | Dev and most examples |
| `docker` | Container boundary |
| `e2b` / `ssh` | Cloud boxes; missing keys fail `--probe` |

`docker` (and `e2b`) need **`environment/Dockerfile`** (or an image option) or lock fails. Same recipe for both.

## Visibility

| Path | Who |
| --- | --- |
| `prompts/`, `data/`, … | Business / maybe agent-visible |
| `evaluation/` | Evaluator only (uploaded at evaluate) |
| `environment/` | Dockerfile, `setup.sh` |

Real isolation is **unmounted + upload at evaluate**, not deleted yaml fields. That is not `path_views`.
