L1 指 Attempt 在 Docker 里跑，而不是宿主进程直接跑 agent。

## 包侧

```yaml
provider:
  kind: docker
  assurance: l1
```

- 需要 `environment/Dockerfile`
- 多 actor 时在配置里声明逻辑分组（shared-container / container-per-group 等，以当前 schema 为准）
- session 需要 `actor_id`；**不会**在失败时悄悄退回本机

## 镜像

官方 Attempt 基座在**构建期**安装常见 engine + ACP 入口。题目镜像应基于基座，不要在 `bora run` 时临时 `npm i`。

探针与示例：[`examples/l1`](https://github.com/ZJU-REAL/BORA/tree/main/examples/l1)。可见性目录见 [Docker 与可见性](/docs/author/docker-and-visibility)。
