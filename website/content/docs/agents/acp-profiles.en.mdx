---

## Recommended config

```yaml
agent_profiles:
  - id: main
    executor: Official/acp
    model: gpt-5.4-mini
    options:
      entry: codex
```

| Field | Note |
| --- | --- |
| `executor` | Use `Official/acp` for coding agents |
| `options.entry` | **Required**; discover with `bora executors -v` |
| `model` | Model id for that entry |
| `api_key` | Optional env **name** |

No command/version/install in package yaml.

## Host readiness

```bash
uv run bora executors -v
```

## Runtime switch

```bash
uv run bora run <dataset> --task <id> \
  --set '/parameters/active_profile="main"'
```

One ACP client in the parent process. Operator path: [Switch agent](/docs/run/switch-agent).
