## Recommended config

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: local
agent_profiles:
  main:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: codex
          # reasoning_effort: high   # optional; must be a value the session advertises
    model: gpt-5.4-mini
```

| Field | Note |
| --- | --- |
| `executor` | Use `acp` for coding agents |
| `- plugin: acp` / `options.entry` | **Required**; discover with `ageval executors -v` |
| `options.reasoning_effort` | Optional. Entries with an advertised thinking selector use `set_config_option`. `grok-build` adds `--reasoning-effort` on `grok agent … stdio` |
| `options.idle_timeout_seconds` | Optional stall ceiling during `session/prompt`. Any `session/update` or permission resets it. Unset / ≤0 → wall-clock invoke timeout only. Fires `acp_idle_timeout` (still capped by the Parent wall) |
| `model` | Model id for that entry |
| `api_key` | Optional env **name** |

No command/version/install in package yaml.

Evaluate-phase ACP (for example `judge`) on a named map must `Agent.session("judge", environment="<name>")`; attach targets that scoring host. Naming a host during run, or omitting the name when the map is set, fails once. HTTP judges ignore `environment=`. See [Write an evaluator](/docs/author/write-evaluator).

## Host readiness

```bash
uv run ageval executors -v
```

`-v` also reports `credential_missing` when every declared credential env name is unset and the binding has no `api_key`. Entries that require a key (for example `pi`) fail closed at `--probe` / session-open; entries that document keyless (OAuth) auth warn only. The child environment is allowlisted (`PATH` / `HOME` / `LANG`, the entry’s credential names, and the binding’s `api_key` / `base_url`). Undeclared host tokens do not reach the entry.

## Runtime switch

```bash
uv run ageval run <dataset> --task <id> \
  --set '/parameters/active_profile="main"'
```

One ACP client in the parent process. Operator path: [Switch agent](/docs/run/switch-agent).
