## Recommended config

```yaml
# Database profiles.yaml
bindings:
  main:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: codex
          # reasoning_effort: high   # optional; must be a value the session advertises
    model: gpt-5.4-mini
```

| Field | Note |
| --- | --- |
| `executor` | Use `acp` for coding agents |
| `- plugin: acp` / `options.entry` | **Required**; discover with `bora executors -v` |
| `options.reasoning_effort` | Optional; applied after model bind to the advertised thinking selector |
| `model` | Model id for that entry |
| `api_key` | Optional env **name** |

No command/version/install in package yaml.

## Host readiness

```bash
uv run bora executors -v
```

## Runtime switch

```bash
uv run bora run <dataset> --task <id> \
  --set '/parameters/active_profile="main"'
```

One ACP client in the parent process. Operator path: [Switch agent](/docs/run/switch-agent).
