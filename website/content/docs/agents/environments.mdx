---
title: 环境 kind
description: local / docker / e2b / ssh / daytona，同一条 ACP 链。
---

环境是 job 文档上的独占槽 `environment`。赢家以该名进入服务表；ACP 只 **inject** 这个名字和 `attach_stdio`，不写 `plugin_id: docker`。换 kind 不必改 ACP。`exec` 是同一服务上的一次性命令，不是第二种环境。

| kind | 怎么开 | 真跑条件 |
| --- | --- | --- |
| `local` | 本机目录 | `examples/datasets/tau3-airline-5` 默认 |
| `docker` | 本机容器 | `examples/datasets/minimal-demo` 默认 `profiles.yaml` |
| `e2b` | 云 sandbox | `E2B_API_KEY`；extra：`uv tool install 'ageval-cli[e2b]'`；缺 extras/钥 `--probe` `ready: false` |
| `ssh` A | 远端整机 | `AGEVAL_SSH_HOST` / `USER` / `KEY` |
| `ssh` B | 远端已有 image | 同上，且 `image:` 已在远端 |
| `daytona` | 云 sandbox（OCI snapshot） | `DAYTONA_API_KEY`；缺钥 `--probe` `ready: false`。默认 CI 不跑真 Daytona |

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg
ageval run examples/datasets/tau3-airline-5 --task airline-00
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg --probe
```

缺 extras 或钥时 `--probe` 应 `ready: false`、`started: false`。ACP 只使用 `attach_stdio`，代码里不应出现 `container_id`。

**ssh A 不支持 live ACP stdio。** 该面上的 dsh / nooa 走 `host.exec`，不是 ACP 长会话。

`environment/setup.sh` 是 environment 末槽，不是独立 phase。gold（`evaluation/`）在 evaluate 才进打分 Host。`profiles.yaml` 可写 `evaluate_host.isolated: true`（Current：`docker`）：另起打分配方环境，gold 只上第二环境；省略 = 同一环境。

多只打分镜像（闭包不同、顺序 stage）写在成员 `evaluation.environments`：每个名字一份 `dockerfile` 和/或 `docker_image`，放 `environment/evaluate/<name>/`，不要放 gold 树。Runtime 第一次 `scoring.exec` / `session(environment=)` 才 start 那只；未点名的不 build。写出该表则必须 isolated + docker，且忽略 `environment/evaluate.Dockerfile`。ACP 点名那只 Host；HTTP judge 忽略 `environment=`。`--agent` 与 `--profiles` 互斥。`--model` 须配合 `--agent`。
