## `tau3-airline`

把 [tau2-bench](https://github.com/sierra-research/tau2-bench)（τ³-bench）的 **airline** 域接到 BORA 外层生命周期上的转换包：`user` / `service` 双角色经 ACP 对话，工具与 DB 在包内 bridge 中执行，PASS 仍只来自独立 evaluator（与 harness 完成态脱钩）。整域约 50 个成员任务；跨 task 的 bridge 与领域资产放在根目录 `shared/lib`、`shared/assets`，避免每个 task 再复制一份 `lib/`（布局约定见 [Package 布局](/docs/author/package-layout)）。

本机完整 run 需要包内 `requirements.txt` 里的 `tau2` pin；只做 `bora lock` 不必装。包内说明见仓库 [`examples/tau3-airline/README.md`](https://github.com/ffy6511/BORA/blob/main/examples/tau3-airline/README.md)。入仓或发布 **不** 等于证据等级升级。

## 仅 Hub 发布的转换包

本仓库 `examples/` **只**收录体量较小的 **`tau3-airline`**。其他热门 bench 转换**不**再镜像进 monorepo，只通过 BORA Hub 发布包 + 上传 suite，以控制 clone 体积与 CI 路径：

| 上游 | Hub 包 id（组织 `my-lab`） | 说明 |
| --- | --- | --- |
| Terminal-Bench 2.0 | `terminal-bench-2` / 轻量 `terminal-bench-2-10` | L1 Docker + Harbor 风格 pytest 评测 |
| MARBLE coding | `marble-coding` / 轻量 `marble-coding-10` | L1 shared-container 多 agent coding |

包上架、Hub 发布或 suite job 上榜 **都不** 等于证据等级升级（`package ≠ real-benchmark-verified`）。
