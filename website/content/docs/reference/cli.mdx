以本机 `uv run bora --help` 为准。

```bash
uv run bora tasks <dataset>
uv run bora lock <dataset> --task <id>
uv run bora run <dataset> --task <id>
uv run bora run <dataset>                         # suite
uv run bora run <dataset> --max-concurrent-tasks 2
uv run bora run <dataset> -k 5                    # Always-k（每题 k 次）
uv run bora run <dataset> --resume-suite <suite_run_id> --task <id> -k 5
uv run bora campaign <dataset> --task <id> ...
uv run bora status <suite_run_id> --database <dataset>
uv run bora cancel <suite_run_id> --database <dataset>
uv run bora executors -v
uv run bora plugin install <path|ref>
uv run bora plugin list
uv run bora plugin uninstall <plugin_id>
uv run bora evidence --help
uv run bora view <dataset> [--dev] [--open /jobs/<id>]
uv run bora jobs delete --local <dataset> --job <id> --yes
# Registry / 结果（需 login；细节见 [Registry](/docs/share/registry)）
uv run bora publish <dataset> --org <org> [--draft] [--public] [--replace]
uv run bora release <database_id> [--public] [--replace]
uv run bora registry list|show|set-visibility|delete …
uv run bora results upload|upload-suite|share|unshare|set-visibility|delete …
```

路径 = Dataset 根（含 `bora.yaml`）。删除类命令须显式 `--yes`；同 identity 覆盖须显式 `--replace`（默认 409）。

## `bora run` 常用选项

| 选项 | 含义 |
| --- | --- |
| `--task <id>` | 只跑该成员；省略 = 整包 suite |
| `--max-concurrent-tasks N` | 并行 unit 上限；**只加速**，不改 k / PASS |
| `--n-attempts` / `-k N` | Always-k：每题 N 次独立 Attempt（默认 1）；**CLI/job only** |
| `--resume-suite <suite_run_id>` | 并进已有 job：跳过已完成 unit，追加 Attempt，重算 pass@k / pass^k |
| `--keep-workspace` | 仅 L1：清理后保留 host `l1-work/`（默认删除；上传不打包）。Docker volume 仍删除 |
| `--set` / `--profiles` | 见下；与 job binding 相关 |

## `status` / `cancel`

| 命令 | 含义 |
| --- | --- |
| `bora status <run_id\|suite_run_id>` | ControlStore；suite 可加 `--database` 读 `progress.json`（系统 id 默认为 8 hex） |
| `bora cancel <run_id\|suite_…>` | 单 Run 或 suite job；suite 可加 `--database` 写 `cancel.requested` |

## `--set`

格式：`<JSON Pointer>=<JSON 值>`，可重复。

| 指针 | 含义 |
| --- | --- |
| `/parameters/seed` | 业务 seed 等 |
| `/parameters/active_profile` | 切换 profile |
| `/bindings/<role>/options/<key>` | job binding 覆盖（含 `entry`、插件 `agent` 等；ACP 仍拒绝 `command` / engine 键） |
| `/limits/wall_time_seconds` | 墙钟（intent；**不可**覆盖 — 见下） |

Intent `limits.*` **不能**经 `--set` 覆盖。其它指针在 lock 阶段失败。
