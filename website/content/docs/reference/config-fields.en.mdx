## Root `bora.yaml`

| Field | Rules |
| --- | --- |
| `format` | `bora.database/1` |
| `database_id` | 1–128; charset `^[a-z0-9]([a-z0-9._/-]*[a-z0-9])?$`; no `..` / `//` |
| `version` | Non-empty |
| `tasks.root` | Default `tasks` |
| `defaults` | Only `max_concurrent_tasks` (≥1) |
| Forbidden | harness / provider / limits / evaluation / profiles |

**Not** in yaml: `n_attempts` / Always-k (CLI/job only — see [Suite](/docs/run/suite)).

Empty suite fails lock.

## Member `task.yaml`

| Block | Notes |
| --- | --- |
| `format` | `bora.task/1` |
| `task_id` | = dir name = `--task` |
| `harness` | `runtime` + `entrypoint` |
| `parameters` | For harness; common keys: `active_profile`, `harness_timeout_seconds`, `agent_timeout_seconds`, `roles`, `seed` |
| `provider` | `local` \| `docker` (+ Dockerfile) |
| `agent_profiles` | Role slots `{id}` only; ACP `entry` lives on Database `- plugin: acp`; `api_key` = env name |
| `limits` | wall / invokes / env actions / memory |
| `artifacts` | publishable id + path |
| `evaluation` | entrypoint, network, inputs, output; optional `tmpfs_mb` (L1 clean-eval `/tmp`, positive MiB, default 32; **not** `limits.*`) |
| `provenance` | optional; member replaces root |

## Job binding (`profiles.yaml`)

Optional `label` on a role is the Jobs / Hub Agents axis. If omitted: ACP uses `- plugin: acp` / `options.entry`, other kinds use `executor`. Never treat `options.agent` as a display name. Optional `options.reasoning_effort` must match an advertised thinking value; `grok-build` applies it on `grok agent --reasoning-effort`, other entries use ACP `set_config_option`.

Optional `overlays` is that role’s published file set for the Runtime plaza (Database-relative paths under `overlays/`). Omit or `[]` = YAML only, no tree. Core does not infer the list from plugin `src`. Listed files stay locator-only.

## Allowed top-level dirs

`prompts` · `schemas` · `environment` · `evaluation` · `data` · `lib` · `upstream` · `solution`

## Common lock failures

id mismatch · bad format · illegal database_id · docker without Dockerfile · missing ACP entry · secrets in yaml · illegal folders · empty suite
