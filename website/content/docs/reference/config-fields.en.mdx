## Root `ageval.yaml`

| Field | Rules |
| --- | --- |
| `format` | `ageval.dataset/1` |
| `dataset_id` | 1–128; charset `^[a-z0-9]([a-z0-9._/-]*[a-z0-9])?$`; no `..` / `//` |
| `version` | Non-empty |
| `tasks.root` | Default `tasks` |
| `defaults` | Only `max_concurrent_tasks` (≥1) |
| Forbidden | `harness` / `provider` / `limits` / `evaluation` / profiles |

**Not** in yaml: `n_attempts` / Always-k (CLI/job only — see [Suite](/docs/run/suite)).

Empty suite fails lock. Unknown format → `invalid_format`.

## Member `task.yaml`

| Block | Notes |
| --- | --- |
| `format` | `ageval.task/1` |
| `task_id` | = dir name = `--task` |
| `parameters` | For `run.py` (`ctx.params`) |
| `agent_profiles` | Role slots `{id}` only; ACP `entry` lives on root `profiles.yaml` |
| `limits` | wall / invokes / env actions / memory |
| `artifacts` | publishable id + path |
| `evaluation` | optional inputs / output; `evaluator.py` is recognized. Optional `tmpfs_mb` (in-environment evaluator `/tmp`, positive MiB, default 32; **not** `limits.*`) |
| `provenance` | optional |
| Forbidden | `harness:` block, `provider.kind`, `assurance`, `executor` / `api_key` on the member role |

Files present are recognized: `run.py`, `evaluator.py`, Dockerfile, `setup.sh`.

## Job binding (`profiles.yaml`)

```yaml
format: ageval.profiles/1
environment: docker
agent_profiles:
  solver:
    executor: acp
    api_key: ${ZHIPU_API_KEY}
    options:
      entry: pi
    extensions:
      - plugin: acp
      - plugin: docker
```

Optional `label` on a role. `--agent` is mutually exclusive with `--profiles`. Optional `overlays` paths must start with `overlays/` and stay locator-only.

## Allowed top-level dirs

`prompts` · `schemas` · `environment` · `evaluation` · `data` · `lib` · `upstream` · `solution`

## Common lock failures

id mismatch · bad format · illegal dataset_id · docker without Dockerfile · missing ACP entry · secrets in yaml · illegal folders · empty suite
