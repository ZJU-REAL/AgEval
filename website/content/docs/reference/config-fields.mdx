## 根 `ageval.yaml`

| 字段 | 规则 |
| --- | --- |
| `format` | `ageval.dataset/1` |
| `dataset_id` | 1–128；`^[a-z0-9]([a-z0-9._/-]*[a-z0-9])?$`；禁 `..` / `//`；推荐 `org/name` |
| `version` | 非空 |
| `tasks.root` | 默认 `tasks` |
| `defaults` | 仅 `max_concurrent_tasks`（≥1） |
| 禁止 | `harness` / `provider` / `limits` / `evaluation` / `agent_profiles` |

**不在** yaml 里：`n_attempts` / Always-k（只走 CLI/job，见 [Suite](/docs/run/suite)）。

空 suite → lock 失败。未知 format → `invalid_format`。

## 成员 `task.yaml`

| 区块 | 要点 |
| --- | --- |
| `format` | `ageval.task/1` |
| `task_id` | = 目录名 = `--task` |
| `parameters` | 给 `run.py`（`ctx.params`） |
| `agent_profiles` | 成员只写 `{id}`；ACP `entry` 写在根 `profiles.yaml` |
| `limits` | wall / agent_invocations / environment_actions / memory_mb |
| `artifacts.publishable` | id + path + producer |
| `evaluation` | 可选 inputs / output；有 `evaluator.py` 就认。可选 `tmpfs_mb`（环境内 evaluator `/tmp`，正整数 MiB，省略 32；**不是** `limits.*`）。可选 `environments`：按名打分 Host（`dockerfile` 和/或 `docker_image`）；写出则必须 job `evaluate_host.isolated: true` + `environment: docker`，并忽略 `evaluate.Dockerfile` |
| `provenance` | 可选 |
| 禁止 | `harness:` 块、`provider.kind`、`assurance`、角色上的 `executor` / `api_key` |

有文件就认：`run.py`、`evaluator.py`、`environment/Dockerfile`、`environment/setup.sh`。

## Job binding（`profiles.yaml`）

```yaml
format: ageval.profiles/1
environment: docker
agent_profiles:
  solver:
    executor: acp
    api_key: ${ZHIPU_API_KEY}
    options:
      entry: pi
    extensions:
      - plugin: acp
      - plugin: docker
```

role 上可选 `label`。缺省：ACP 用 `options.entry`，其它路径用 `executor`。**不要**把 `options.agent` 当展示名。`--agent` 与 `--profiles` 互斥。`--model` 须配合 `--agent`。

可选 `overlays` 是该 role 在 Hub 上的发布文件集（路径必须以 `overlays/` 开头）。列出的文件只能含 locator，不能含密钥。

可选 `evaluate_host.isolated: true`（Current：docker）：另起打分环境。与成员 `evaluation.environments` 一起用时，Runtime 按名懒启动多只 Host。

## 成员一级目录白名单

`prompts` · `schemas` · `environment` · `evaluation` · `data` · `lib` · `upstream` · `solution`

## lock 常见失败

task_id 不一致 · format 错 · dataset_id 非法 · docker 无 Dockerfile · ACP 缺 entry · 密钥写进 yaml · 非法一级目录 · 空 suite
