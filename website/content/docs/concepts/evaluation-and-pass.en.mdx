## Red lines

1. `HarnessTerminal.completed` is **not** PASS  
2. Trajectory / usage / agent self-report is **not** PASS  
3. PASS comes only from an **independent evaluator**, then Core binds the Result  

## Barrier

After harness completion, Core stops writers, materializes gold / hidden inputs, and runs the evaluator in a clean environment.

Suites may record observational `pass_rate` / `mean_score`, but there is **no suite-level PASS authority** — PASS stays per-task.
