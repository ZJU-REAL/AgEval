## 为什么要轨迹

复现失败、对比多后端、训练管线都需要**可导出的运行事实**。BORA 把 Attempt evidence（含 trajectory）当作产品交付物。

## 不是什么

- 轨迹 **不是** PASS 来源  
- 缺轨迹时 **不得** 发明 PASS  
- secret / token **不得** 写入 evidence  

本机浏览见 [Viewer](/docs/operations/viewer)；导出见 [Evidence export](/docs/operations/evidence-export)。
