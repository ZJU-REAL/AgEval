## 两层直觉

| 级别 | 含义 |
| --- | --- |
| **L0 host** | 本机进程路径；适合开发与部分公开 smoke |
| **L1 Docker** | Attempt 在容器内；mount / UID / network 由 Provider 执行 |

## 可见性投影

gold 与 evaluator-only 材料靠 **不 mount + 评测前 materialize**，禁止只靠「配置里删字段」。

L1 多 actor 可声明 `shared-container` 或 `container-per-group`；YAML 只描述逻辑拓扑，container id / UID 由 Runtime 拥有。

设计：[`docs/design/05`](https://github.com/ffy6511/BORA/blob/main/docs/design/05-runtime-core.md)、[`06`](https://github.com/ffy6511/BORA/blob/main/docs/design/06-capability-adapter-visibility.md)。
