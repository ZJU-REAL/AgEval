## 分工

| 层 | 拥有 | 不拥有 |
| --- | --- | --- |
| **Package harness** | loop、角色、本地 Tool、handoff 数据 | PASS、credential、隔离 mount |
| **Harness Core（`bora_sdk`）** | `HarnessContext`、`AgentSession`、Tool guard 等薄客户端 | Run identity、Provider 控制、final PASS |
| **BORA Core** | lock、Attempt、Provider、Capability、evaluator barrier | 业务 workflow |

## 实践

Harness 通过 SDK 打开 session 并 `invoke`，而不是直接 import 某家 coding-agent SDK 当 Core。  
`HarnessTerminal.completed` **不等于** PASS。

机制：[`docs/design/03`](https://github.com/ffy6511/BORA/blob/main/docs/design/03-harness-layer.md)、[`04`](https://github.com/ffy6511/BORA/blob/main/docs/design/04-harness-core-sdk.md)。
