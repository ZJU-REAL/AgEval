## 红线

1. `HarnessTerminal.completed` **≠** PASS  
2. 轨迹 / usage / Agent 自述 **≠** PASS  
3. PASS 只能来自 **独立 evaluator**，再由 Core 绑定到 Result  

## Barrier

Harness 结束后进入 evaluator barrier：停止 writer，按 allowlist materialize gold / hidden，再在 clean 环境跑 evaluator。

Suite 可汇总观测用的 `pass_rate` / `mean_score`，但 **不存在 suite 级 PASS 权威**——PASS 仍 per-task。

设计：[`docs/design/07`](https://github.com/ffy6511/BORA/blob/main/docs/design/07-budget-evaluation-failure.md)。
