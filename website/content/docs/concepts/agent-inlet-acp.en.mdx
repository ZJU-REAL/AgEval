## Target shape

```yaml
agent_profiles:
  - id: main
    executor: acp
    options:
      entry: codex   # or pi / opencode / claude-code / grok-build …
```

- The parent process owns the **only** ACP JSON-RPC client  
- Vendor-private translation runs **outside** BORA (shim / native / vendor package)  
- **No** second vendor stdout scraper inside BORA  

## L1 base image

The official Attempt image bakes in minimum engines + ACP entries at **build** time. No runtime `npm i` / floating `npx`.

Honest status: public smokes and residuals follow code and [GitHub Issues](https://github.com/ffy6511/BORA/issues). Product decision: [`docs/design/05` §8.4.3a](https://github.com/ffy6511/BORA/blob/main/docs/design/05-runtime-core.md).
