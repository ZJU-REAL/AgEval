## 权威链

```text
docs/design  →  ARCHITECTURE.md  →  GitHub Issues  →  代码
website/     →  读者向用法（非真理）
```

## 怎么开工

1. 开或认领 [GitHub Issue](https://github.com/ffy6511/BORA/issues)（Acceptance / 非目标 / 证据）  
2. 改机制先改 `docs/design/`，改结构先改 `ARCHITECTURE.md`  
3. 实现与测试；PR 链 Issue  
4. 若用户可见行为变了，同步 `website/` 对应页  

## 不要做的事

- 不要新建 `specs/` / Active Spec / ROADMAP 勾选机  
- 不要把 secret 写进 yaml / lock / evidence  
- 不要用轨迹或 harness completed 充当 PASS  
- 不要按 Benchmark 名写 Adapter  

Agent 路由全文见仓库 [`AGENTS.md`](https://github.com/ffy6511/BORA/blob/main/AGENTS.md)。
