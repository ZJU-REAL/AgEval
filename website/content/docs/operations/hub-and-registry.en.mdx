## Split

| Component | Owns |
| --- | --- |
| **Registry** | Standalone HTTP: publish / packages / results / OAuth |
| **Hub** (`apps/hub`) | Human SPA: catalog, README, files, job lists, Leaderboard |
| **Viewer** | **Local** suite runs only |

## User path

1. Start Registry ([`services/registry/README.md`](https://github.com/ffy6511/BORA/blob/main/services/registry/README.md))  
2. Start Hub:

```bash
cd apps/hub
pnpm install
pnpm dev   # proxies /v1 → Registry by default
```

3. Open Hub: browse Datasets → package README / Tasks → Leaderboard or Jobs list  
4. Login (e.g. GitHub device flow) follows current implementation and deploy policy

## Hub routes

| Path | Page |
| --- | --- |
| `/datasets` | List |
| `/datasets/:id` | README · Tasks · Leaderboard |
| `/datasets/:id/tasks/:task` | README · Files · Jobs (list) |
| `/login` | Login shell |

## Honest boundaries

- Hub is **not** `bora view`  
- Click-through from Jobs into full Attempt evidence may still be in progress — trust [Issues](https://github.com/ffy6511/BORA/issues), not optimistic docs  
- Public access / allowlist policy is operational, not invented here
