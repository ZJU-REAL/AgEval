## 分工

| 组件 | 职责 |
| --- | --- |
| **Registry** | 独立 HTTP 服务：publish / packages / results / OAuth |
| **Hub** (`apps/hub`) | 面向人的 SPA：目录、README、Files、Jobs 列表、Leaderboard |
| **Viewer** | **本机** suite 跑次；不替代 Hub |

## 用户路径（直觉）

1. 启动 Registry（见仓库 [`services/registry/README.md`](https://github.com/ffy6511/BORA/blob/main/services/registry/README.md)）  
2. 启动 Hub：

```bash
cd apps/hub
pnpm install
pnpm dev   # 默认代理 /v1 → Registry
```

3. 浏览器打开 Hub：浏览 Datasets → 打开包 README / Tasks → 看 Leaderboard 或 Jobs 列表  
4. 登录（GitHub device flow 等）按当前实现与部署策略

## 路由（Hub）

| 路径 | 页面 |
| --- | --- |
| `/datasets` | 列表 |
| `/datasets/:id` | README · Tasks · Leaderboard |
| `/datasets/:id/tasks/:task` | README · Files · Jobs（列表） |
| `/login` | 登录壳 |

## 诚实边界

- Hub **不是** `bora view`  
- Jobs **点进完整 Attempt evidence** 等能力若仍在讨论中，以 [Issues](https://github.com/ffy6511/BORA/issues) 为准，站点不假装已完成  
- 公网开放与 allowlist 策略亦以 Issue / 运维配置为准
