title: CLI
description: Public bora command map.
---

Trust local `uv run bora --help`. Common paths:

```bash
uv run bora tasks <dataset>
uv run bora lock <dataset> --task <id>
uv run bora run <dataset> --task <id>
uv run bora run <dataset>                    # suite: omit --task
uv run bora campaign <dataset> --task <id>   # parameter matrix
uv run bora executors -v
uv run bora evidence ...
uv run bora view <dataset>
```

Allowlisted `--set` pointers are defined in CLI code; illegal overrides fail closed at lock.

Deeper failure semantics: skill `bora-cli` and [`src/bora/cli/README.md`](https://github.com/ffy6511/BORA/blob/main/src/bora/cli/README.md).
