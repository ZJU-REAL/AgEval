## 是什么

**Viewer** 是本机 SPA，浏览某个 Dataset 下 `.bora/suite-runs/` 里的 suite 跑次：

**Jobs → Tasks → Attempt（trial / run_id）**

适合：跑完 suite 后对照分数、钻进轨迹、复制 `bora run` 命令。

## 怎么用

```bash
# 首次：构建 SPA
cd apps/viewer
pnpm install
pnpm build

# 仓库根
uv run bora view examples/core
# 或
uv run bora view examples/core --no-browser --port 8765
```

Python 只服务已构建的 `apps/viewer/dist/`。端口占用时换 `--port`。

## 你会看到什么

| 层 | 内容 |
| --- | --- |
| **Jobs** | 本地 suite runs |
| **Tasks** | 每 task 状态 / 分数 / run 引用 |
| **Attempt** | outcome、actors（Time / Usage）、证据 tabs |

Attempt tabs（有文件才显示）：Trajectory · Agent · Verifier · Artifacts · Lock · Runtime。  
多角色时 Trajectory / Agent 树按 `profile_id` 分组。

## 诚实边界

- Time / Usage **只是观测**，不是 PASS  
- 轨迹 **不是** 评分权威  
- **不**连接 Registry；远程目录与 Leaderboard 见 [Hub](/docs/operations/hub-and-registry)
