---
title: CLI
description: 公开 bora 命令速览。
---

以本机 `uv run bora --help` 为准。常用：

```bash
uv run bora tasks <dataset>
uv run bora lock <dataset> --task <id>
uv run bora run <dataset> --task <id>
uv run bora run <dataset>                    # suite：省略 --task
uv run bora campaign <dataset> --task <id>   # 参数矩阵
uv run bora executors -v
uv run bora evidence ...
uv run bora view <dataset>
```

允许的 `--set` 指针以 CLI 实现 allowlist 为准；非法 override 在 lock 阶段 fail closed。

更细的失败语义见 skill `bora-cli` 与仓库 [`src/bora/cli/README.md`](https://github.com/ffy6511/BORA/blob/main/src/bora/cli/README.md)。
