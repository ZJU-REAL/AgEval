## Requirements

| Dependency | Requirement |
| --- | --- |
| [uv](https://docs.astral.sh/uv/) | Recommended installer |
| CPython | **3.12+** |
| Coding agent (optional) | Real `bora run` needs a host ACP entry and credentials |

## Install

```bash
git clone https://github.com/ffy6511/BORA.git
cd BORA
uv sync --frozen --all-packages
uv run bora -V
```

## Three commands

```bash
# List tasks in a Dataset
uv run bora tasks examples/core

# Lock only (no agent / evaluator)
uv run bora lock examples/core --task config-minimal

# Real multi-turn agent path (host ACP entry + credentials required)
uv run bora run examples/core --task sdk-agent-session
```

A successful `bora run` prints a `logs` locator for Attempt evidence.

## Inspect results

```bash
# Build the local SPA once
cd apps/viewer && pnpm install && pnpm build && cd ../..

uv run bora view examples/core --no-browser
```

Open the printed URL and browse **Jobs → Tasks → Attempt**. See [Viewer](/docs/operations/viewer).

## Let a coding agent drive it

Skills under [`skills/`](https://github.com/ffy6511/BORA/tree/main/skills) are discoverable via `.agents/skills`:

| Skill | Use when |
| --- | --- |
| `bora-platform` | Product map and red lines |
| `bora-cli` | CLI and result interpretation |
| `bora-config-package` | Authoring Dataset / task config |
| `bora-sdk-harness` | Writing harnesses with `bora_sdk` |

## Honest boundaries

- Without credentials or an ACP entry, real agent paths fail or skip — expected.
- Fixture tests alone do not prove public smoke.
- Full CLI map: [CLI](/docs/operations/cli).
