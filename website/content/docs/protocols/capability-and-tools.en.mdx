---
title: Capability and tools
description: Authorization before external effects; local tool boundaries.
---

The **Capability API** describes external abilities an Attempt may request (agent / env / workspace…).  
Package-local tools may compose inside the harness, but external resources still cross Runtime boundaries.

Adapters are named by **protocol / resource / execution mechanism** (`acp`, `postgresql`, docker…) — never by benchmark or task name.

Design: [`docs/design/06`](https://github.com/ffy6511/BORA/blob/main/docs/design/06-capability-adapter-visibility.md).
