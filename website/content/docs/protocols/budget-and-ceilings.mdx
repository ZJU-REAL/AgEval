---
title: 预算与硬顶
description: 硬顶在 effect 前强制；事后 token/cost 只作观测。
---

| 类型 | 行为 |
| --- | --- |
| **硬顶（hard ceiling）** | Runtime/Provider 在执行前拒绝越界 |
| **观测 usage** | 事后 token / cost / latency；**不等于** hard budget |

Harness 不可自提硬顶。细节见 [`docs/design/07`](https://github.com/ffy6511/BORA/blob/main/docs/design/07-budget-evaluation-failure.md)。
