---
title: ageval 是什么
description: 一份 dataset 写一次，换环境和 Agent 只改配置。
icon: BookOpen
---

大多数 Agent 评测仍停留在**模型**：同一套提示、同一套工具约定，比较不同权重或不同 API。可交付的 Agent 是模型加上它的运行时。同一套权重接到不同的 coding agent、工具策略或环境上，行为和成本都会变。分数要带上用了哪个 Agent 运行时、哪套环境，不能只报模型名。

**ageval**（agent eval）把环境和 Agent 写进配置。换哪边都不必改 dataset 里的题面。

CLI 与包名是 `ageval`。交付单位是 dataset。
