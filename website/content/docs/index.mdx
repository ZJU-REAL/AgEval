---
title: BORA 是什么
description: 为 Agent 测评提供可复现的外层运行边界。
icon: BookOpen
---

在 Agent 测评中，模型分数往往被单独关注，而编排流程、可见范围与评分权威却分散在各厂商实现中。更换 coding agent 或执行环境后，结果与轨迹难以对齐。

**BORA**（Bounded Orchestration for Runtime Agents）提供这一外层边界：锁定 Dataset 配置，在约定边界内执行 Attempt，控制可见范围，并由**独立评测**给出结果。轨迹用于复盘与分析，**不得作为评分依据**。
