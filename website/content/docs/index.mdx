---
title: ageval 是什么
description: 锁定 dataset，打开盒子，由独立 evaluator 出分。
icon: BookOpen
---

Agent 评测常只盯模型分数，把编排、可见范围和打分权威留在各家实现里。换 coding agent 或换盒子，结果与轨迹就对不齐。

**ageval**（agent eval）提供这层外层边界：锁定 dataset，在约定盒子里跑 Attempt，控制可见范围，并由**独立评测**给出结果。轨迹用于复盘，**不得作为评分依据**。

CLI 与包名是 `ageval`。题包根叫 dataset，不是 SQL。
