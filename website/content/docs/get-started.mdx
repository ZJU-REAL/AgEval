## 环境

| 依赖 | 要求 |
| --- | --- |
| [uv](https://docs.astral.sh/uv/) | 推荐安装方式 |
| CPython | **3.12+** |
| Coding agent（可选） | 真实 `bora run` 需要本机 ACP entry 与凭据 |

## 安装

```bash
git clone https://github.com/ffy6511/BORA.git
cd BORA
uv sync --frozen --all-packages
uv run bora -V
```

## 三条命令

```bash
# 列出 Dataset 内 task
uv run bora tasks examples/core

# 只锁定（不启 agent / evaluator）
uv run bora lock examples/core --task config-minimal

# 真实多轮 agent 路径（需本机 ACP entry + 凭据）
uv run bora run examples/core --task sdk-agent-session
```

`bora run` 成功时会给出 `logs` locator，指向本次 Attempt 证据目录。

## 看结果

```bash
# 先构建本机 SPA 一次
cd apps/viewer && pnpm install && pnpm build && cd ../..

uv run bora view examples/core --no-browser
```

浏览器打开提示的地址，按 **Jobs → Tasks → Attempt** 浏览。详见 [Viewer](/docs/operations/viewer)。

## 让 coding agent 帮你跑

仓库 [`skills/`](https://github.com/ffy6511/BORA/tree/main/skills) 可通过 `.agents/skills` 发现：

| Skill | 用途 |
| --- | --- |
| `bora-platform` | 产品地图与红线 |
| `bora-cli` | CLI 与结果解读 |
| `bora-config-package` | 写 Dataset / task 配置 |
| `bora-sdk-harness` | 用 `bora_sdk` 写 harness |

## 诚实边界

- 无凭据或无 ACP entry 时，真实 agent 路径会失败或被跳过——这是预期。
- Fixture 测试不能单独证明公开 smoke。
- 更完整的 CLI 表见 [CLI](/docs/operations/cli)。
