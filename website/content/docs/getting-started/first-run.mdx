---
title: 首次运行
description: lock 配置、跑示例 task，并找到结果目录。
---

CLI 路径参数始终是 **dataset 根**（含 `ageval.yaml` 的目录），不是 `tasks/<id>/`。

公开示例以 [`examples/datasets/minimal-demo`](https://github.com/ZJU-REAL/ageval/tree/main/examples/datasets/minimal-demo) 为主。默认 `profiles.yaml` 的环境是 **docker**。

```bash
uv run ageval tasks examples/datasets/minimal-demo
uv run ageval lock examples/datasets/minimal-demo --task terminal-jsonl-agg
uv run ageval run  examples/datasets/minimal-demo --task terminal-jsonl-agg
uv run ageval run  examples/datasets/minimal-demo --task terminal-jsonl-agg \
  --profiles examples/datasets/minimal-demo/profiles.e2b-acp.yaml --probe
```

`ageval run` 在 TTY 下打印短 recap（单题含 `logs` 路径，整份 dataset 含 `summary` 路径）。管道或 `--json` 仍输出 JSON 文档。证据在 `.ageval/runs/<id>/`。

| 词 | 说明 |
| --- | --- |
| **dataset** | 根 `ageval.yaml` + 若干 task |
| **一次运行** | 一次 lock 之后的执行；目录 `.ageval/runs/<id>/` |
| **环境** | 本机 / Docker / e2b / ssh / daytona |

```bash
uv run ageval executors -v
uv run ageval view examples/datasets/minimal-demo --no-browser
```

`--probe` 只做 lock + preflight，不 invoke。`--profiles` 整份替换配置文件。`--agent` 与 `--profiles` 互斥。`--model` 须配合 `--agent`。
