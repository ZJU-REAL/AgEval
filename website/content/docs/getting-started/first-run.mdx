以下示例使用仓库内 `examples/core`。CLI 路径参数始终为 **Dataset 根目录**（包含 `bora.yaml` 的目录），而不是 `tasks/<id>/`。

## 基本命令

```bash
# 列出 Dataset 内的 task
uv run bora tasks examples/core

# 仅锁定配置（不启动 agent、不评测）
uv run bora lock examples/core --task config-minimal

# 执行真实多轮 agent 路径（需要本机 ACP 入口与凭据）
uv run bora run examples/core --task sdk-agent-session
```

`bora run` 成功时会输出 **`logs` 路径**，指向本次 Attempt 的证据目录。

### 相关术语

| 术语 | 说明 |
| --- | --- |
| **Dataset** | 可交付套件：根目录 `bora.yaml` + 若干 task 成员 |
| **Attempt** | 在锁定配置与边界约束下的一次执行（含 harness / agent / 评测） |

## 无 agent 时的验证

`config-minimal` 仅验证 lock。若 `sdk-agent-session` 因入口缺失失败，先执行：

```bash
uv run bora executors -v
```

完成对应 ACP 入口安装与登录后再运行。详见 [ACP Profiles](/docs/agents/acp-profiles)。

## 本地查看结果（可选）

```bash
cd apps/viewer && pnpm install && pnpm build && cd ../..
uv run bora view examples/core --no-browser
```

在浏览器中打开终端给出的地址，按 **Jobs → Tasks → Attempt** 浏览。详见 [本地结果查看器](/docs/run/local-viewer)。
