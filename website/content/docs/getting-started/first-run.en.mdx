---
title: First run
description: Lock config, run a sample task, find the result directory.
---

CLI paths are always the **dataset root** (the directory with `ageval.yaml`), not `tasks/<id>/`.

```bash
uv run ageval tasks examples/core
uv run ageval lock examples/core --task config-minimal
uv run ageval run  examples/core --task acp-local-min
uv run ageval run  examples/core --task acp-docker-min --profiles examples/core/profiles.docker.yaml
```

A successful `ageval run` prints `logs` / `evidence_path` under `.ageval/runs/<id>/`.

| Term | Meaning |
| --- | --- |
| **dataset** | Root `ageval.yaml` plus task members |
| **Attempt** | One execution under a locked config |
| **environment** | Box kind: local / docker / e2b / ssh |

```bash
uv run ageval executors -v
uv run ageval view examples/core --no-browser
```

`--probe` is lock + preflight only. `--profiles` replaces the job document. `--agent` and `--profiles` are mutually exclusive.
