---
title: First run
description: Lock config, run a sample task, find the result directory.
---

CLI paths are always the **dataset root** (the directory with `ageval.yaml`), not `tasks/<id>/`.

The public smoke is [`examples/datasets/minimal-demo`](https://github.com/ZJU-REAL/ageval/tree/main/examples/datasets/minimal-demo). Default `profiles.yaml` uses **docker**.

```bash
uv run ageval tasks examples/datasets/minimal-demo
uv run ageval lock examples/datasets/minimal-demo --task terminal-jsonl-agg
uv run ageval run  examples/datasets/minimal-demo --task terminal-jsonl-agg
uv run ageval run  examples/datasets/minimal-demo --task terminal-jsonl-agg \
  --profiles examples/datasets/minimal-demo/profiles.e2b-acp.yaml --probe
```

On a TTY, `ageval run` prints a short recap (single task: `logs`; full dataset: `summary` path). A pipe or `--json` still writes the JSON document. Evidence lives under `.ageval/runs/<id>/`.

| Term | Meaning |
| --- | --- |
| **dataset** | Root `ageval.yaml` plus task members |
| **Attempt** | One execution after lock; directory `.ageval/runs/<id>/` |
| **environment** | Host / Docker / e2b / ssh / daytona |

```bash
uv run ageval executors -v
uv run ageval view examples/datasets/minimal-demo --no-browser
```

`--probe` is lock + preflight only. `--profiles` replaces the profiles file. `--agent` and `--profiles` are mutually exclusive. `--model` requires `--agent`.
