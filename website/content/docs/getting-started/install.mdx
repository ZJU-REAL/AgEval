## 环境要求

- [uv](https://docs.astral.sh/uv/)
- CPython **3.12+**

真实 coding agent 路径需要本机 ACP 入口与凭据。仅 `ageval lock` 不需要 agent。

```bash
git clone https://github.com/ZJU-REAL/BORA.git
cd BORA
uv sync --frozen --all-packages
uv run ageval -V
```

GitHub 路径仍是 `ZJU-REAL/BORA`。命令是 `ageval`。
