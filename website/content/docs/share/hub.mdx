Hub（`apps/hub`）是给人用的网页，连 Registry：

- Dataset 列表与 README  
- Task 文件预览  
- Jobs 列表、Leaderboard（按已实现能力）  

## 本地开发打开

```bash
# Registry 先起好
cd apps/hub
pnpm install
pnpm dev
```

| 路径 | 页面 |
| --- | --- |
| `/datasets` | 列表 |
| `/datasets/:id` | README · Tasks · Leaderboard |
| `/login` | 登录 |

## 和 Viewer 的区别

| | Viewer | Hub |
| --- | --- | --- |
| 数据 | 本机 `.bora/suite-runs/` | Registry |
| 命令 | `bora view` | 浏览器打开 Hub |

Jobs 点进完整 Attempt 等能力若仍在建设中，以 Issues 为准。前端细节：`apps/hub/README.md`。
