Registry 是独立的 HTTP 服务：发包、管组织、存结果、登录。  
它**不是**本机 Viewer，也**不是** BORA Core。

## 怎么用

1. 按仓库 [`services/registry/README.md`](https://github.com/ffy6511/BORA/blob/main/services/registry/README.md) 启动服务  
2. CLI 登录后创建组织、带组织发布 Dataset、按需上传 suite / Attempt 结果  
3. 私有结果可以分享给某个组织或用户  
4. 用浏览器打开 [Hub](/docs/share/hub) 浏览；Hub 走浏览器 OAuth，CLI 走 Device Flow  

具体命令以 `bora --help` 和 registry README 为准。

## 所有权（摘要）

| 对象 | 归属 | 谁能读私有内容 |
| --- | --- | --- |
| 包（Dataset release） | **组织** | 组织成员 / admin |
| Attempt / suite 结果 | **上传者** | 本人 / 被分享对象 / admin |

加入组织**不会**自动看到别人的私有结果，除非对方分享给你。  
邀请码在创建时只完整展示一次，之后只能看到前缀。

公网是否开放、谁能上传，由部署方决定。
