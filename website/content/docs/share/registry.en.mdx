Registry is a standalone HTTP service: publish packages, read files, store results, login.  
It is **not** the local Viewer.

## Flow

1. Start it per [`services/registry/README.md`](https://github.com/ffy6511/BORA/blob/main/services/registry/README.md)  
2. Upload / list via CLI (see `bora --help` and the registry README)  
3. Browse in [Hub](/docs/share/hub)  

Public access policy is operational — trust current deploy settings and Issues.
