---
title: 本地结果查看器
description: 浏览器里翻本机跑次，不连 Registry。
---

整份 dataset 跑完或只跑一题后，想对照分数、点开轨迹、复制命令——用 Viewer。它读打开的那一个 Dataset：`.ageval/suite-runs/` 与 `.ageval/runs/`，不连 Registry。

Jobs 表可以删掉本机一行 Job（先 preview 路径，再确认）。删 suite 会一并删掉它引用的全部 Attempt，不会再以 single 冒出来。不能从 suite 里单独删一条 Attempt。这是擦本地证据，不是 Registry 删除（`ageval results delete` 是另一对象）。CLI 对等：`ageval jobs delete --local <dataset> --job <id> --yes`。

置顶和备注只存在**这个浏览器**，不写进 evidence / lock / Registry。

## 打开

```bash
# 首次构建前端（生产 ageval view）
cd apps/viewer && pnpm install && pnpm build && cd ../..

ageval view examples/datasets/minimal-demo
# 或
ageval view examples/datasets/minimal-demo --no-browser --port 8765
# 已缓存的 Hub ref（唯一命中不打 Hub）
ageval view official/demo@0.1.0

# 开发：一条命令（能起 Vite 就起；否则打印两行 fallback）
ageval view examples/datasets/minimal-demo --dev --port 8765

# 跑完后深链到该 job / task / run
ageval view examples/datasets/minimal-demo --open /jobs/<id>
```

`--dev` 对着**同一套**本地 API，并尽量自己拉起 Vite。起不了会在终端打印 `pnpm --dir apps/viewer dev`。两进程：API 端口（默认 8765）+ UI 端口（默认 5173）。服务的生产包是 `apps/viewer/dist/`。端口占用就换 `--port`。

## 界面结构

**Jobs → Tasks → Attempt**

| 层 | 内容 |
| --- | --- |
| Jobs | 本地 suite 跑次 **和** 单题 Attempt（Kind：suite / single）。Kind / Source 是过滤器；suite 的 Source 只列 task id |
| Tasks | 每题状态 / 分数。suite 题且只有 1 次 Attempt 时，点进后直接打开该 Attempt |
| Attempt | 结果条、**Timing**（有数据时还有 **Tokens**）、角色、证据页签（Trajectory / Agent / …） |

Timing 来自 Attempt `phase_timing`（prepare / run / evaluate / cleanup）；hover 色条看分段耗时。  
轨迹按轨迹文件顺序展示：一段 thought，紧接着它调用的工具，再下一段 thought。轨迹行（thought / `tool_call` / 最终 assistant）若带 `elapsed_ms`，步骤头会显示该步耗时；没有就不画标签——Viewer 不会用文件 mtime 或页面时钟补造。  
耗时、token、单步耗时 **只是参考**，不是 PASS。轨迹也不是评分依据。Trajectory 里每条 **tool-call**（以及过长行）可折叠；观测 PASS 条上有全部展开 / 全部收起，与 Hub Attempt 页一致。

**Verifier**：缺省是 `result.json` + `evaluation/` 文件树。若有 `evaluation/observation.jsonl`（evaluate 阶段 SDK invoke，LLM-as-judge），该页签复用 Trajectory 的步骤卡片；Agent 的 Trajectory 页仍只读根 `trajectory.jsonl`。观察不是 PASS。

Viewer **不连** Registry；远程目录走 Hub。改 SPA 看仓库 `apps/viewer/README.md`。
