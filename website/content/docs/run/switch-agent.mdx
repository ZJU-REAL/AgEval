---
title: 切换 Agent 与模型
description: 用 profile 和 --set 切换 coding-agent 入口。
---

同一题可以声明多个 `agent_profiles`，运行时换「用谁」。

## 先看本机有什么

```bash
uv run ageval executors -v
```

关注 ACP entry 的 `engine_ready` / `acp_entry_ready`。yaml 写对了但本机没装，照样跑不起来。

## 配置里声明

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: local
agent_profiles:
  solver:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: codex
    model: gpt-5.4-mini
  # 或换一条 agent_profiles / --profiles / --set
  # solver:
  #   executor: acp
  #   options:
  #     entry: pi
```

## 临时切换（不用改文件）

```bash
uv run ageval run examples/core --task builtin-executor-conformance \
  --set '/parameters/active_profile="pi-mini"'
```

`--set` 只允许白名单指针，例如 `/bindings/solver/options/reasoning_effort="high"`；完整列表见 [CLI](/docs/reference/cli)。

`api_key` 永远写**环境变量名**，不要写密钥本身。更多 profile 规则见 [ACP profiles](/docs/agents/acp-profiles)。

非 ACP 机制（nooa / dsh / miniswe）用 `--profiles` 整份替换，见 [机制插件](/docs/run/plugins)。
