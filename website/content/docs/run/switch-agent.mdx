---
title: 切换 Agent 与模型
description: 用 profile、--agent、--model 或 --set 切换 coding-agent 入口。
---

同一题可以声明多个 `agent_profiles`，运行时换「用谁」。

## 先看本机有什么

```bash
ageval executors -v
```

关注 ACP entry 的 `engine_ready` / `acp_entry_ready`。yaml 写对了但本机没装，照样跑不起来。

## 配置里声明

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: docker
agent_profiles:
  solver:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: pi
    model: gpt-5.4-mini
```

ACP 的 `entry` 写在 `- plugin: acp` / `options.entry`。

## Agent 包（`--agent`）

`ageval.agent/1` 是 harness 包（executor、entry、overlays）。`binding.model` 是缺省，不是身份。内置 Agent 包（`pi`、`opencode`、`codex`、`claude-code`、`grok-build`、`openai-http`、`anthropic-http`）随 ageval 提供，不必 `agent install`。定制 overlays 包仍是 `org/name@version`，先装再绑。`ageval agent install` 会顺带安装 `binding.extensions[].plugin`（contrib 跳过；缺插件或 `host_requires` 不满足则整条失败，不能进入运行）。`--agent` 与 `--profiles` **互斥**。`--model` 改这次 run 已绑角色的模型；省略则用包缺省。不要和 `ageval results upload-suite --model`（上传观测标签）搞混。

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg --agent pi --model glm-4.7
ageval agent install examples/agents/pi-default
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg --agent local/pi-default@0.1.0
```

## 临时切换（不用改文件）

```bash
ageval run examples/datasets/minimal-demo --task terminal-jsonl-agg \
  --set '/bindings/solver/options/entry="codex"'
```

`--set` 只允许白名单指针，例如 `/bindings/solver/options/reasoning_effort="high"`；完整列表见 [CLI](/docs/reference/cli)。

`api_key` 永远写**环境变量名**，不要写密钥本身。更多 profile 规则见 [ACP profiles](/docs/agents/acp-profiles)。

非 ACP 机制（nooa / dsh / miniswe）用 `--profiles` 整份替换，见 [机制插件](/docs/run/plugins)。
