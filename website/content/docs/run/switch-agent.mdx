---
title: 切换 Agent 与模型
description: 用 profile、--agent 或 --set 切换 coding-agent 入口。
---

同一题可以声明多个 `agent_profiles`，运行时换「用谁」。

## 先看本机有什么

```bash
uv run ageval executors -v
```

关注 ACP entry 的 `engine_ready` / `acp_entry_ready`。yaml 写对了但本机没装，照样跑不起来。

## 配置里声明

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: docker
agent_profiles:
  solver:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: pi
    model: gpt-5.4-mini
```

ACP 的 `entry` 写在 `- plugin: acp` / `options.entry`。

## Agent 包（`--agent`）

`ageval.agent/1` 是独立包。先装进本机缓存，再用 `--agent` 绑定一次 job。`--agent` 与 `--profiles` **互斥**。

```bash
uv run ageval agent install examples/agents/pi-default
uv run ageval agent list
uv run ageval run examples/journeys --task terminal-jsonl-agg --agent pi-default
```

## 临时切换（不用改文件）

```bash
uv run ageval run examples/journeys --task terminal-jsonl-agg \
  --set '/bindings/solver/options/entry="codex"'
```

`--set` 只允许白名单指针，例如 `/bindings/solver/options/reasoning_effort="high"`；完整列表见 [CLI](/docs/reference/cli)。

`api_key` 永远写**环境变量名**，不要写密钥本身。更多 profile 规则见 [ACP profiles](/docs/agents/acp-profiles)。

非 ACP 机制（nooa / dsh / miniswe）用 `--profiles` 整份替换，见 [机制插件](/docs/run/plugins)。
