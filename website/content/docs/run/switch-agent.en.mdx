---
title: Switch agent and model
description: Swap coding-agent entries with profiles and --set.
---

One task can declare several `agent_profiles` and pick which to use at run time.

## What’s on this host?

```bash
uv run ageval executors -v
```

Check `engine_ready` / `acp_entry_ready` per ACP entry.

## Declare in config

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: local
agent_profiles:
  solver:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: codex
    model: gpt-5.4-mini
```

## Temporary switch

```bash
uv run ageval run examples/core --task builtin-executor-conformance \
  --set '/parameters/active_profile="pi-mini"'
```

Only allowlisted `--set` pointers work, e.g. `/bindings/solver/options/reasoning_effort="high"` — see [CLI](/docs/reference/cli).

`api_key` is always an env **name**, never the secret. More: [ACP profiles](/docs/agents/acp-profiles).
