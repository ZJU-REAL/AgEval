---
title: Switch agent and model
description: Swap coding-agent entries with profiles, --agent, --model, or --set.
---

One task can declare several `agent_profiles` and pick which to use at run time.

## What’s on this host?

```bash
uv run ageval executors -v
```

Check `engine_ready` / `acp_entry_ready` per ACP entry.

## Declare in config

```yaml
# profiles.yaml
format: ageval.profiles/1
environment: docker
agent_profiles:
  solver:
    executor: acp
    extensions:
      - plugin: acp
        options:
          entry: pi
    model: gpt-5.4-mini
```

ACP `entry` lives on `- plugin: acp` / `options.entry`.

## Agent packages (`--agent`)

`ageval.agent/1` is a harness package (executor, entry, overlays).
`binding.model` is the default, not identity. Mechanism cards (`pi`,
`opencode`, `codex`, `claude-code`, `grok-build`, `openai-http`,
`anthropic-http`) ship with
ageval — no `agent install`. Custom overlay packs are `org/name@version` after
install. `ageval agent install` also installs `binding.extensions[].plugin`
(skips contrib; missing plugin or unsatisfied `host_requires` fail-closes the
whole install). `--agent` and `--profiles` are mutually exclusive. `--model` overrides
this run’s model on the roles `--agent` bound; omit it to keep the package
default. This is not `ageval results upload-suite --model` (an observational
upload label).

```bash
uv run ageval run examples/journeys --task terminal-jsonl-agg --agent pi --model glm-4.7
uv run ageval agent install examples/agents/pi-default
uv run ageval run examples/journeys --task terminal-jsonl-agg --agent local/pi-default@0.1.0
```

## Temporary switch

```bash
uv run ageval run examples/journeys --task terminal-jsonl-agg \
  --set '/bindings/solver/options/entry="codex"'
```

Only allowlisted `--set` pointers work, e.g. `/bindings/solver/options/reasoning_effort="high"` — see [CLI](/docs/reference/cli).

`api_key` is always an env **name**, never the secret. More: [ACP profiles](/docs/agents/acp-profiles).

Non-ACP mechanisms (nooa / dsh / miniswe) switch with a whole `--profiles` file. See [Mechanism plugins](/docs/run/plugins).
