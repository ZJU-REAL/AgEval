## Background

### Problem

`v0.3` 能在 validated workdir 中启动、终止并清理真实 L0 process，但 Runtime 仍没有向一次 Attempt 暴露受限操作面的 production authority。若调用方直接持有完整 lock、任意 workspace 路径或未来 Adapter，Runtime 无法统一拒绝跨 Attempt、terminal 后、未声明或超额请求，也无法证明未授权外部效果从未开始。

### Current Behavior

- 当前仓库仍为 `design-only`；Spec 00–02 尚未实施，production Capability、authority 与 receipts 均不存在。
- 本 Spec 的合同基线是经用户验收的 `v0.3`：`bora lock` 可用，Lifecycle 与 Provider L0 application suites 已验证 identity、真实 process、writer stop 与 cleanup；在 `B1` 解除前不得把该合同写成当前实现事实。
- `bora_sdk`、package Harness entrypoint、真实 AgentExecutor、真实 Environment、Artifact materializer、Evaluator 与 `bora run` 均未交付。

### Goals and Non-goals

- Goal: 完整交付 Roadmap `v0.4` 的 Runtime-side Capability Core，使每个 params/scope/agent/environment/workspace/artifacts/events handle 绑定同一 Attempt、共享 open/closed gate，并在调用前执行 declaration、scope、deadline/cancel 与 availability 检查。
- Goal: 对 `limits.agent_invocations` 与 `limits.environment_actions` 提供 `count_on=authorized` 的进程内单 Attempt hard ceiling；最后一个额度可启动 delegated effect，下一请求在 effect start 前拒绝。
- Goal: 用 production authority + production Capability + test-only sinks 证明授权顺序、receipt identity 与 denied-no-effect；test sink 不进入 production composition，也不升级真实 Adapter 证据。
- Non-goal: 本 Spec 不实现 `bora_sdk`、`HarnessContext`、package entrypoint/bootstrap、正式 `HarnessTerminal` 或 package code 注入；这些属于 `v0.5`。
- Non-goal: 本 Spec 不实现真实 AgentExecutor、Agent Service 后端路由、credential/network projection、真实 Environment Adapter、Artifact materialization、Evaluator、Result、PASS 或 `bora run`；真实 Agent 与 Evaluation 属于 `v0.6`，真实 Environment 属于 `v0.10`。
- Non-goal: L0 workspace capability 只校验 declared view 与 canonical path；它不能阻止同 UID 代码绕过 Capability 直接访问宿主文件、socket、network 或 secret。Docker/mount/path-view/credential 的物理强制属于 `v0.8`。
- Non-goal: 本 Spec 不承诺跨线程、跨 event loop、跨进程、跨 Attempt 共享额度、durable transaction、restart/reopen、crash recovery 或 token/cost 硬顶；durable/cross-process authority 属于 `v0.12`，未具备调用前 reserve 的维度保持 unsupported。
- Evidence boundary: 本 Spec 完成后证据等级仍为 `design-only`；fixture-backed effect 不能声明 `runnable-mvp`、`isolated`、真实 Agent/Environment 或 real-benchmark verification。

### Key Insight

`v0.4` 的交付单位是 Runtime-owned authorization boundary。Capability 方法拥有 delegated sink，先在共享 Attempt authority 内完成 scope 与额度决策，再以内部 authorization grant 启动 sink；调用方不能绕过 Capability 取得 sink。真实 Adapter 尚未交付时，只有测试装配提供可观测 sink，production composition 对相应 effect 显式返回 unavailable。

### Extension Seams

- Delegated effect seam: Capability owns一个窄 `start_authorized(grant, request) -> awaitable` port；production 默认 absent，`v0.6`/`v0.10` 分别接入真实 Agent/Environment implementation，不让 authority 按 backend、Benchmark、task 或 action 名分支。
- Capability transport: 本版使用进程内 non-serializable handles；`v0.5` 的 task runtime bridge 可以承载同一 scope/decision contract，但不能绕过 Runtime authority。
- Quota store: 本版只实现 single-loop in-memory Attempt counters；`v0.12` 可替换为 durable transaction authority，Capability surface 不从事后 usage 推导硬顶。

>
> Local delta: 冻结 `v0.4` 的 Runtime-internal bundle、shared gate、scope/declaration checks、authorization-before-start handshake、两项 `count_on=authorized` quota、fixture evidence 与 L0 visibility limitation。SDK/transport、真实 Adapter、physical projection、Evaluator 与 durable authority 由所属版本冻结。

### Control Flow

```text
accepted LockedTaskConfig + AttemptIdentity + PreparedLocalRuntime
  → CapabilityFactory validates one Attempt / one running asyncio loop
  → create AttemptCapabilityAuthority(open) + AttemptCapabilities
  → integration client calls one capability
      → verify same Attempt + open + loop + deadline/cancel
      → verify principal/profile/resource/action/path/artifact declaration
      → verify delegated sink is available
      → for agent/environment: reserve one unit under authority lock
      → append authorized decision and internal one-use grant
      → call sink.start_authorized(...) synchronously before releasing authority lock
      → await delegated completion outside authority lock
      → append completion/failure receipt; authorized unit remains consumed
  → generic Lifecycle harness_terminal boundary closes shared gate once
  → later calls fail `capability_closed`
  → Provider cleanup; application returns immutable CapabilityProbeRecord
```

`run_capability_probe` 不 import/execute package Harness。integration client 只是测试侧调用者；其返回不构成 `HarnessTerminal`、PASS 或 Result。

### Shared Gate and Scope

| Check order | Failure | Effect/quota rule |
| --- | --- | --- |
| Handle/authority Attempt mismatch or rebind attempt | `capability_scope_mismatch` | 无 receipt mutation、无 quota、无 sink call |
| Wrong event loop / cross-thread bridge | `unsupported_concurrency_scope` | 无 quota、无 sink call；本版只支持 factory 所在 loop |
| Shared gate closed | `capability_closed` | 无 quota、无 sink call；close 幂等且 terminal 后不可 reopen |
| Deadline elapsed / cancellation observed | `scope_timed_out` / `scope_cancelled` | 在 authorization 前拒绝；最终进程终止仍由 Lifecycle/Provider 拥有 |
| Unknown profile/resource/action/view/artifact/producer/path | typed undeclared/scope error | 无 quota、无 sink call |
| Delegate absent | `capability_unavailable` | 无 quota、无 grant、无 permissive fallback |
| Hard ceiling exhausted | `hard_limit_exhausted` | 拒绝者无 sink call；既有 authorized count 不变 |
| Authorization succeeds | internal grant + authorized receipt | `count_on=authorized`；随后 delegate failure/cancel 不退款 |
| Delegate start/completion fails | typed delegated-effect error | started/failed 独立 receipt；不得改写 authorization 或其它 Runtime facts |

- 所有 handles 共享一个 authority state，并拒绝 pickle/copy/rebind；每次方法调用仍检查当前 gate，不依赖创建时的一次性检查。
- close 只禁止新读取/授权/启动，不声称撤回调用方已读取的参数、已解析路径或终止已启动 effect。application probe 必须 await 全部 test effects；真实 writer stop 继续由 Provider/Lifecycle 负责。
- principal 只使用 lock 中已有的 profile、workspace view、resource、artifact producer 等声明，不新增 Core-owned Actor registry。

### Hard Ceiling and Concurrency Semantics

| Dimension | Scope / unit | Authority / count point | Supported concurrency | Explicitly unsupported |
| --- | --- | --- | --- | --- |
| `limits.agent_invocations` | one Attempt / one authorized `AgentCapability.invoke` | Runtime `AttemptCapabilityAuthority`; `count_on=authorized` before sink start | 同一 event loop 内多个 asyncio tasks；最后额度由 shared lock 原子仲裁 | thread、other loop/process、shared Run/Trial quota、restart/reopen、token/cost |
| `limits.environment_actions` | one Attempt / one authorized resource action | 同上，独立 counter | 同上 | durable resource reservation、跨 Attempt quota、真实 mutation/teardown（`v0.10`） |

- zero limit 拒绝第一个请求；validation/unavailable/closed/cancel-before-reserve 不消耗。
- authorization 后调用方取消、sink start 抛错、sink await 失败或返回 failure 都保留一次消耗，防止通过故障重试绕过上限。
- 每个 delegated request 只取得一个内部 one-use grant；sink 只能从 Capability 获得 grant。重复使用同一 grant 在 effect start 前拒绝，且不增加第二次 authorized count。
- 事后 provider usage 只进入 observation；本 Spec 不把 token、cost、Tool call、wall time、process、Trial 或 Campaign 描述为 Capability hard ceiling。

### Data and Visibility Boundaries

| Surface | `v0.4` local rule |
| --- | --- |
| `HarnessParameterView` | 只投影递归不可变 `LockedTaskConfig.parameters`；不暴露 provider/evaluation/gold/credential/完整 lock；close 后的新读取失败 |
| `RunScope` | 只读 Attempt identity、deadline、cancel status、remaining time；调用方不能延长 deadline、清除 cancel 或改 identity |
| Agent | 只接受 locked profile id 与 immutable invocation intent；真实 Executor/result/session/credential 不在本版 |
| Environment | `require(resource_id)` 与 `action(action_id, payload)` 只接受 locked resource/action；真实 resource state 不在本版 |
| Workspace | 只解析 declared view 内的相对 path，拒绝 absolute/`..`/symlink escape 与 mode 不匹配；返回 L0 scoped path 不等于 mount/ACL/UID 隔离 |
| Artifact | publish 前校验 logical id、producer、declared relative path 与 scoped source；本版 test sink 只记录 receipt，不 materialize evaluator input |
| Events | 只接受 JSON-compatible generic payload；Runtime 注入 Attempt/principal/sequence，拒绝调用方覆盖 reserved identity fields |
| Receipts | append-only in-memory facts，记录 decision/start/outcome 与 quota snapshot；无 secret/request body，无 durable/reopen 或正式 evidence-store 声明 |

L0 代码仍可绕过 WorkspaceCapability 直接调用宿主文件 API；green path 只能证明 BORA 提供的 path resolution fail closed。`isolated` 证据必须等待 `v0.8` 的物理 path/network/secret projection 与负向验收。

### Reference Interfaces

```python
class AttemptCapabilityAuthority:
    async def authorize(self, request: EffectAuthorizationRequest) -> AuthorizedEffectGrant:
        ...

    def close(self, *, terminal_attempt: AttemptIdentity) -> None:
        ...


@dataclass(frozen=True)
class AttemptCapabilities:
    params: HarnessParameterView
    scope: RunScope
    agent: AgentCapability
    environment: EnvironmentCapability
    workspace: WorkspaceCapability
    artifacts: ArtifactCapability
    events: EventCapability
```

- `AttemptCapabilities` 是 Runtime internal bundle，不在本版创建 `bora_sdk.HarnessContext` 或跨进程序列化 schema。
- `AgentCapability.invoke(profile_id, intent)` 与 `EnvironmentCapability.require(resource_id).action(action_id, payload)` 统一进入 authority；Capability 不解释 Benchmark workflow。
- `ArtifactCapability.publish(logical_name, scoped_path)` 与 `EventCapability.emit(kind, payload)` 使用相同 shared gate/scope checks，但不占用 Agent/Environment quota。
- delegated sink 的 `start_authorized` 必须是短小、同步、non-blocking 的 start boundary，返回 awaitable handle；authority lock 内只完成 grant validation 与 start，不等待外部工作。

实现全部七类 production Capability surfaces，并统一验证 Attempt、open/closed、principal、声明、availability 与 L0 path scope。

### Tasks

- 实现无 raw mapping escape 的 `HarnessParameterView` 与只读 `RunScope`，复用 Lifecycle identity/deadline/cancel source。
- 实现 `AgentCapability`、`EnvironmentCapability` 与 resource client 的 profile/resource/action scope；production 未注入 delegate 时在 reserve 前返回 `capability_unavailable`。
- 实现 `WorkspaceCapability` 的 declared view、mode、canonical relative path 与 symlink containment；输出与文档固定标记 L0 validation-only。
- 实现 Artifact publish 与 generic Event emit 的 declaration/reserved-field checks、receipts 与 delegated sink seam；production 无 sink 时显式 unavailable。
- 实现 non-serialization/non-rebind checks，并添加 params isolation、closed read、workspace escape、undeclared artifact/producer、event identity 与 sink-no-start tests。

## Risks and Mitigations

| Risk | Mitigation |
| --- | --- |
| check-then-start race 让 close/并发请求越过最后额度 | shared authority lock 内完成 validation、reserve、grant 与同步 start boundary；真实 event-synchronized race probe |
| sink failure 或取消被用来退款并绕过硬顶 | `count_on=authorized`；authorization 后任何 start/await outcome 都保留消耗与独立 receipt |
| test sink 被误读为真实 Agent/Environment/Artifact/Event Adapter | sink 仅在 `tests/doubles/`；production default 显式 unavailable；composition/import negative test；输出标记 fixture-backed |
| L0 path validation 被误读为 filesystem isolation | Workspace Capability 和 evidence 固定 `assurance: l0` / validation-only；同 UID bypass 明示；L1 physical negatives 留 `v0.8` |
| closed handle 仍可读取已返回数据或已解析路径 | close 只禁止新操作并如实记录不可撤回限制；secret/gold 从未投影；物理撤权留 Provider L1 |
| cross-Attempt/cross-loop handle 复用或序列化 | Attempt + factory-loop binding、non-serializable handles、每次调用 scope check、close-on-terminal 与负向 tests |
| Capability Core 膨胀成 SDK/Agent Service/Evaluator | 本版只含 Runtime internal bundle/authority 与 delegated seam；无 `bora_sdk`、Executor、session、credential、materialize、verdict 或 `bora run` |
| 进程内 quota 被夸大为 durable authority | receipt 明示 `scope=attempt`、`authority=in-process-single-loop`；cross-process/reopen 负向说明与 `v0.12` destination |
| 未验收 `v0.3` 上累积实现 | Decision Summary 保持 `B1`；Version Index、baseline suites 与用户验收全部通过前不开始 Phase 0 |
