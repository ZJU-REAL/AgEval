## Background

### Problem

`v0.5` 能在 L0 task worker 中运行 package Harness、投影最小 `HarnessContext`、发布 declared artifact 并返回 `HarnessTerminal`，但 Agent 仍不可用，且 worker-local Capability authority 不能直接扩展成真实 Agent authority：credential、profile routing、`limits.agent_invocations` 和 Codex process 必须留在 parent Runtime。与此同时，Harness terminal 尚未经过 writer barrier 与独立 evaluator，用户也没有 production `bora run`、flat Result 或可定位 evidence。

### Current Behavior

- 当前仓库仍为 `design-only`；Spec 00–04 尚未实施，production `bora run`、Agent Service、Codex Executor、Evaluator、Result 与 evidence store 均不存在。
- 本 Spec 的合同基线是经用户验收的 `v0.5`：`bora lock` 可用，application path 可在 L0 task worker 中运行 package Harness、得到 terminal 与 declared artifact；在 `B1` 解除前不得把该合同写成当前实现事实。
- 已只读验证本机 `codex-cli 0.146.0`、`codex login status` 为 ChatGPT 登录，本地 model cache 含 `gpt-5.4-mini`。这些事实不是付费/联网调用授权，也不能替代 Phase 0 的真实 invoke probe。

### Goals and Non-goals

- Goal: 完整交付 Roadmap `v0.6`，使操作者从 clean checkout 通过 production `bora run <package> --task <id>` 驱动 Config、Lifecycle、Provider L0、Harness、Agent Service、Evaluation 与 evidence，并从 CLI 区分 runtime、Harness、agent invocation、evaluation 与 cleanup 事实。
- Goal: 新增 Attempt-scoped 窄 Agent capability channel。task worker 只实现 SDK client、frame/schema/scope/open/deadline 的 fast check；parent Agent Service 是 locked profile、credential binding、`limits.agent_invocations`、Executor start 与 normalized result 的唯一真实 authority。
- Goal: 内置 Codex Executor 只使用 locked profile 中显式 model；`examples/agent-eval` 固定 `gpt-5.4-mini`，不读取用户 default，不在 probe 失败时静默换 model/executor。
- Goal: Harness terminal 后关闭新 Capability，等待/取消 in-flight Agent invocation，停止并确认所有 Provider-owned writers，再按 `evaluation.inputs` allowlist materialize；Evaluator 只在 barrier 关闭后由专用 worker import/执行。
- Goal: 保存 runtime、Harness terminal、agent invocations、evaluator raw、normalized evaluation、cleanup 与 flat Result 为相互独立事实；Harness `completed` 永不直接产生 PASS。
- Goal: Runtime credential binding 只把用户接受的 host locator 注入 Codex Executor subprocess；task worker launch/env/payload、Agent request/response、evaluator worker、CLI、logs 与 evidence 不包含 secret value，Runtime 不复制、序列化或重写 auth bytes。
- Non-goal: 本 Spec 不实现 `v0.7` 的 `AgentSession`、ToolSet/Hook/Guard 或 workflow helpers；Harness 直接使用最小 `ctx.agent.invoke`。
- Non-goal: 本 Spec 不实现 Docker、mount/path-view enforcement、network namespace/policy、UID/GID、host credential 物理不可见性或 clean container。L0 同 UID task/evaluator code 仍可能主动探测宿主资源，本版不得声称 `isolated`。
- Non-goal: 本 Spec 不实现第二 AgentExecutor/plugin discovery、真实 Environment、Campaign、durable/reopen、后台 control、跨进程共享 quota 或 crash recovery；分别由 `v0.9`、`v0.10`、`v0.11`、`v0.12` 承担。
- Non-goal: 本 Spec 不接入真实 upstream Benchmark，不声称 `real-benchmark-verified`；首个 upstream 选择继续由 Roadmap 指向的 Research 负责。

### Key Insight

`v0.6` 的竖切跨越两个互不混淆的进程边界：task worker 经 Agent channel 请求 parent Runtime 启动真实 Codex，Evaluator worker只在 writer barrier 后消费 allowlisted materialization。parent 从不 import task Harness/evaluator 模块，worker 也不持有第二份 Agent quota 或 credential。只有独立 evaluator raw 经 Result Binder 校验后才能形成 PASS/FAIL。

### Runnable Acceptance

- Public entrypoint: `uv run bora run <package> --task <task-id>`，只通过 `src/bora/application/composition.py` 装配 Core 1–5、Agent/Evaluator/evidence Adapters。
- Clean setup: `uv sync --frozen --all-packages`。
- Success smoke: `uv run bora run examples/agent-eval --task agent-eval`；使用 locked `gpt-5.4-mini` 发起至少一次真实 Codex invocation，Harness 发布 declared structured output，独立 evaluator 返回 PASS/score，CLI exit 0。
- Expected failure: `uv run bora run examples/agent-eval --task unknown`；Config 在 Attempt/Agent/evidence 创建前返回 typed unknown-task，CLI exit 2，Codex spawn count为0，无伪Result/PASS或`.bora/runs/<run-id>/`。
- Evaluator negative control: `uv run bora run examples/evaluator-negative --task evaluator-negative`；Harness 返回 completed，但独立 evaluator 对错误artifact返回合法FAIL/score 0，CLI exit 1。
- Barrier failures: automated public-composition tests覆盖 missing declared output、digest mismatch与writer-stop unconfirmed；evaluator spawn count为0，cleanup仍执行，flat Result为error且`error.phase=evaluation_input`。
- Regression smokes: Spec 00–04 的全部 public/application/worker acceptance suites，包含 Config determinism、Lifecycle/Provider cleanup、Capability pre-effect authority和Control Plane no-import。
- Observable CLI result: 固定显示 `run_id`、runtime kind、Harness terminal kind、Agent invocation count/model、evaluation status/score、cleanup warning presence、`assurance: l0` 与 repository-relative evidence path；默认不打印prompt、raw model events、credential或host absolute path。
- Observable evidence: `.bora/runs/<run-id>/` 按本 Spec evidence layout保存独立facts；secret scan通过后，用户验收真实CLI输出/evidence才允许把限定范围等级更新为`runnable-mvp`。

### Extension Seams

- AgentExecutor: Agent Service依赖窄`AgentExecutor.invoke`，本版只装配内置Codex；`v0.9`可增加entry point/第二后端，Harness和Agent channel不按backend分支。
- Agent transport: SDK `ctx.agent.invoke`不暴露socket/frame。worker client与parent server适配同一Capability语义；未来L1或其它transport不改变Harness API和parent authority。
- Evaluator runner: parent只依赖worker launcher/raw schema；task evaluator逻辑在package worker内，未来L1 clean evaluator container替换placement而不改变barrier/binder。
- Evidence store: application依赖窄append/atomic-write interface；本版只实现local filesystem，不引入数据库、registry或第二实现。

### End-to-End Control Flow

```text
operator: `bora run <package> --task <id>`
  → CLI/application `load_and_lock`
      → failure: exit 2; no Run/Attempt/Agent/evidence
  → create Run/Trial/Attempt + `.bora/runs/<run-id>/` temporary evidence
  → Provider L0 prepares task workspace and task worker
  → parent opens task control channel + Agent capability channel
  → task worker imports Harness and calls `run(ctx)`
      → `ctx.agent.invoke(profile_id, messages, output_schema)`
          → worker fast scope/frame check; no quota/credential
          → parent Agent Service validates Attempt/open/deadline/profile
          → parent checks executor + credential availability
          → parent authority reserves `agent_invocations` (`count_on=authorized`)
          → parent Codex Executor direct-spawns `codex exec`
          → normalize AgentResult; return bounded response to worker
      → Harness publishes declared output and returns HarnessTerminal
  → parent records Harness fact; close Agent/new Capability starts
  → wait/cancel Agent invocations; stop/reap task + Executor writers
  → if writer stop confirmed: materialize only `evaluation.inputs`
  → launch dedicated evaluator worker with no credential/Agent channel
      → worker alone imports evaluator and returns raw output
  → parent validates raw → binds normalized Evaluation + flat Result
  → persist separate facts → final Provider/evaluator cleanup
  → cleanup warning appended without rewriting valid score
  → CLI summary + stable exit code
```

Control Plane处理locator、wire DTO、facts和Adapter；它从不import/execute task-local `harness.py`或`evaluator.py`。task/evaluator exception object不跨进程，只有bounded typed envelope/raw data跨边界。

### Agent Capability Channel and Authority

| Surface | `v0.6` rule |
| --- | --- |
| Channel ownership | parent为每个Attempt创建第二个dedicated socketpair/session；只把worker endpoint作为显式FD grant；与launch/terminal channel分离 |
| Worker client | 检查local Attempt/session、open、deadline/cancel、known profile id、frame/output-schema size；发送request并等待response；不持credential、locked executor/model/options、quota counter、authorization grant或Executor handle |
| Parent Agent Service | 从accepted lock重新解析profile→executor/model/options/workspace view；验证channel Attempt/open/deadline/cancel；检查credential/Executor availability；拥有唯一`agent_invocations` counter与one-use grant |
| Pre-effect boundary | parent完成validation→availability→reserve→authorized receipt→Codex process start；只有process start成功进入effect-start fact；denied request永不调用Executor spawn |
| Count semantics | `scope=Attempt`、`unit=authorized invocation`、`count_on=authorized`、single parent process；authorization后launch/result/cancel失败不退款；worker永不镜像remaining count作为authority |
| Response | bounded normalized `AgentResult`：content、validated structured output、usage observation、executor/model、optional null session；不回传raw credential、CLI auth/config、process handle或unfiltered JSONL |
| Closure | Harness terminal/parent failure先拒绝新request，再等待或取消in-flight Executor；channel EOF/duplicate/wrong Attempt/oversize frame为runtime infrastructure failure并进入writer stop/cleanup |

`v0.4` worker-local authority继续服务params/workspace/artifact/event的local checks；真实Agent effect在`v0.6`明确迁到parent authority。worker可以缓存只读scope descriptor用于fast reject，但不能把它命名为Agent quota、不能本地扣减，也不能在parent denial后启动任何fallback。

### Codex Executor and Credential Boundary

Phase 0真实probe与production Executor使用同一命令形状；具体temporary paths由Runtime生成，tracked文档不记录宿主绝对路径：

```text
CODEX_HOME=<executor-only-host-locator> codex exec
  --ephemeral
  --ignore-user-config
  --ignore-rules
  --model gpt-5.4-mini
  --sandbox read-only
  --cd <attempt-agent-workspace>
  --skip-git-repo-check
  --output-schema <runtime-schema-path>
  --output-last-message <runtime-output-path>
  --json
  -
```

- Executor direct-spawns resolved Codex executable，`shell=False`，prompt经stdin，model来自locked profile，schema/output/workdir由Provider生成；禁止读取CLI default model或在失败后改用其它model。
- `--ignore-user-config`避免用户config改变model/provider/policy，auth仍由Runtime指定的executor-only `CODEX_HOME` host locator提供；credential store是用户接受的host Codex login capability，环境变量只承载locator。L0不复制auth bytes，也不宣称该host path已被物理隐藏。
- task worker/evaluator worker使用各自explicit minimal env，结构上无`CODEX_HOME`/auth locator；Agent channel不传credential。L0同UID代码可能主动发现host auth路径，这一物理旁路只能在`v0.8`关闭。
- Executor使用`--ephemeral`，不把provider session当作跨Attempt可恢复状态；v0.6 `session_handle`固定为null/unsupported。
- JSONL只由Executor Adapter解析；evidence默认保存model、usage、latency、event kinds、request/output schema digest和terminal，prompt/raw reasoning/credential不持久化。
- credential binding登记敏感值/bytes与host locator的redaction fingerprints；真实probe与public smoke扫描worker payload/env snapshot、Codex stdout/stderr summary、Agent response、CLI与整棵run evidence。扫描器只报告location/kind，不回显敏感值或绝对locator。

### Writer Barrier and Evaluator Worker

```text
Harness returned/failed
  → close new Agent/Capability starts
  → settle or cancel in-flight Codex subprocesses
  → stop/reap task worker + Provider-owned child groups
  → require writer_stop=confirmed
  → revalidate published artifact path/digest/producer
  → copy only locked `evaluation.inputs` into fresh staging root
  → launch evaluator worker with minimal env, no credential/Agent FD
  → evaluator worker alone imports task evaluator
  → validate raw output
  → bind Evaluation/Result
  → cleanup staging + Attempt resources
```

- barrier前不读取evaluator module，不创建evaluator worker。missing artifact、digest mismatch、undeclared producer/path或writer-stop unconfirmed形成`evaluation_input` error，evaluator spawn count保持0。
- materialization manifest固定logical input、source artifact digest、consumer/evaluator与staged relative path；Evaluator只接收manifest/staging root和task/evaluation identity，不接收full lock、Agent credential、mutable Harness memory或Agent channel。
- Evaluator worker是独立L0 process与dedicated one-request/one-raw channel；parent不importevaluator。worker env显式不含credential，working root只stage allowlisted input和evaluator code。
- L0 logical clean只证明BORA没有向evaluator注入credential locator或其它未声明input；没有mount/network namespace，同UID evaluator code仍可能探测宿主路径或network。`isolated`与hidden-material物理negative属于`v0.8`。
- evaluator raw contract至少含`format: bora.evaluation/1`、`status: pass | fail`、finite `score`、JSON-compatible `metrics`；unknown fields/NaN/invalid schema/multiple raw envelopes为evaluation infrastructure error。

### Fact Model, Result and Evidence Layout

| Fact | Owner | Persisted projection |
| --- | --- | --- |
| Runtime | Lifecycle/Provider | identities、locked digest、phase/terminal、`assurance:l0`、process/writer facts；不含score |
| Harness | task worker | terminal kind/reason、artifact receipts；completed不含PASS |
| Agent invocation | parent Agent Service | request id/profile/executor/model、authorization/start/outcome、usage observation、schema digests；不含credential/raw prompt |
| Evaluator raw | evaluator worker | schema-validated task-local raw envelope，独立保存；不能改写runtime/Harness/Agent事实 |
| Evaluation | Result Binder | normalized pass/fail、score、metrics或typed evaluation error |
| Cleanup | Provider/evaluator/materializer | per-resource outcome/warning；不覆盖已形成evaluation |
| Flat Result | Result Binder | `status`、optional `score/metrics`、optional `error.phase/kind/message`、optional `cleanup_warning`、`logs: run://<run-id>` |

`.bora/runs/<run-id>/` 最小稳定布局：

```text
lock.json
runtime.json
harness.json
agent-invocations.jsonl
artifacts/manifest.json
evaluation-inputs/manifest.json
evaluator/raw.json
evaluation.json
cleanup.json
result.json
```

- `lock.json`是secret-free locked summary，不复制credential material；文件均以temporary sibling + fsync/atomic replace写入，事实形成后不静默重写为另一类事实。
- `evaluator/raw.json`只在worker返回合法raw frame后出现；未启动时由`evaluation.json`记录`not_started` reason，不伪造空raw。
- partial infrastructure failure仍保留已形成的前序facts；`result.json`最后绑定。cleanup失败在`cleanup.json`和`cleanup_warning`出现，不撤销已有pass/fail/score。
- evidence对外只使用repository-relative locator/`run://`identity；不持久化host absolute package/auth/credential-locator path。

### CLI Exit and Output Semantics

| Exit | Meaning | Flat Result / evidence |
| --- | --- | --- |
| `0` | 独立 evaluator 返回合法`pass` | `status=pass`，有score/metrics/evidence |
| `1` | 独立 evaluator 返回合法`fail`/低分 | `status=fail`，仍是有效Benchmark result；negative control使用此码 |
| `2` | CLI/request/Config在Attempt前失败，例如unknown task | 无Run/Attempt/Agent/evidence/伪Result；stderr typed error |
| `3` | Attempt后的runtime/Harness/Agent/Provider infrastructure error | `status=error`、`error.phase`精确分类，保留partial evidence |
| `4` | evaluation-input/evaluator/raw-validation infrastructure error | `status=error`；`error.phase`为`evaluation_input`、`evaluator`或`result_binding` |
| `124` | Attempt deadline timeout | `status=timeout`，进入writer stop/cleanup并保留evidence |
| `130` | 用户/parent cancellation | `status=cancelled`，进入writer stop/cleanup并保留evidence |

cleanup warning不改变上述exit/status；CLI stdout仅在Run形成后输出一份bounded JSON summary，stderr用于pre-Run或human-readable infrastructure detail且经过redaction。默认输出不得把Harness completed显示为pass。

### Failure Semantics

| Condition | Primary fact/result | Required closure |
| --- | --- | --- |
| Unknown task/profile/executor | Config error before Attempt | no Agent/evidence；exit 2 |
| Agent channel scope/frame/EOF failure | runtime Agent infrastructure error | close Agent authority/channel；cancel Executor；stop worker；no evaluator unless accepted Harness terminal/output仍满足明确策略，本版fail closed不启动 |
| Parent quota exhausted | typed Agent denial returned to Harness | Executor spawn count不变；Harness决定失败terminal；authorization事实保留 |
| Codex login/model/network/schema/output failure | Agent invocation failed + runtime error if unhandled | no model fallback；reap Executor；Harness可形成failed terminal；barrier/cleanup仍执行，Evaluator不把infra error当低分 |
| Harness completed + valid artifact | Harness fact only | barrier后Evaluator决定pass/fail |
| Missing/changed artifact or writer unconfirmed | evaluation-input infrastructure error | evaluator不启动；cleanup；exit 4 |
| Evaluator合法fail | valid evaluation fail | flat status fail/score；cleanup；exit 1 |
| Evaluator crash/malformed/multiple raw | evaluation infrastructure error | preserve evaluator raw diagnostic摘要；cleanup；exit 4 |
| Cleanup failure after valid score | pass/fail保持 | add cleanup warning；exit仍0/1 |
