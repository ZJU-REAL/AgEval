## Background

### Problem

`v0.9` 的合同基线已提供L1物理隔离、两种AgentExecutor与独立Evaluator，但Harness尚不能通过Runtime-owned lifecycle使用真实有状态资源。若Task Package自行启动数据库、持有admin credential或让Agent直连endpoint，Runtime无法在mutation前执行action allowlist/hard ceiling，也无法统一health、freeze、teardown与cleanup evidence。若shared Adapter根据Benchmark/task/action名称拼SQL，又会把业务workflow搬进Core并破坏第二领域通用性。

### Current Behavior

- `EnvironmentCapability`与`limits.environment_actions`已有声明/进程内authority检查点，但没有真实resource instance、Manager、Adapter、health、action transport或teardown。
- v0.8 Provider可提供Attempt-local container/network/path/credential投影；v0.9 Agent plugin复用同一grant边界。本版只在这些已验收合同上增加一种真实resource type。
- [首个真实 Benchmark 选型 Research](../research/2026-08-02-v1-reference-and-first-benchmark-selection-research.md)仍为`open`，尚未固定upstream/task/platform，因此本Spec不得把仓库example写成`real-benchmark-verified`。
- Roadmap `v0.1`–`v0.9`的内部实现事实与未勾选Version Index保持原样；本Spec只新增规划。

### Goals and Non-goals

- Goal: 提供按资源类型命名的`postgresql` Environment Adapter，通过Runtime Environment Manager完成Attempt-bound prepare、health、allowlisted action、可选freeze/getter、teardown与evidence。
- Goal: Task Package保留业务Tool/action mapping与SQL/参数构造；Environment Core只理解resource id、declared action id、generic operation、payload、deadline、idempotency key与locked resource config。
- Goal: Runtime在Adapter开始前校验Attempt/resource/action scope、resource state、cancel/deadline与`limits.environment_actions`，以process-local原子reservation仲裁最后额度；授权后失败/取消不退款。
- Goal: PostgreSQL container、network、volume与least-privilege role均为Attempt-local；Agent/Harness不获得数据库credential或直连route，只有Environment Adapter能访问resource endpoint。
- Goal: public success通过真实Agent选择一个package-local Tool，Tool调用Environment Capability完成真实mutation/observation，writer barrier后由PostgreSQL freeze/getter生成固定evaluator input，独立Evaluator形成Result，最后teardown。
- Goal: 用第二个不同业务领域Task Package只改`bora.yaml` binding与package-local code接入同一Adapter，shared module不新增Benchmark/task/domain/role/action分支。
- Non-goal: 本Spec不提供通用SQL business action catalog、ORM、数据库管理平台、长期共享数据库、跨Attempt资源池、durable transaction authority或crash后重放。
- Non-goal: 本Spec不把Harness local `ToolSet`/`CallLimit`提升为Runtime权限；外部mutation始终由Environment authority独立决定。
- Non-goal: 本Spec不实现Browser/VM/多服务编排、Campaign、background/reopen或全局resource registry；分别留给后续版本或Research。
- Evidence boundary: 本版完成只证明限定PostgreSQL resource/example的真实Environment lifecycle与第二领域绑定。`real-benchmark-verified`只有在独立Research固定upstream revision/task/platform，且真实Agent/Environment/evaluator/cleanup public journey经用户验收后才可另行声明。

### Key Insight

Environment Adapter的通用性来自“资源协议 + lifecycle”，不是业务action名称。Runtime先对`action_id`和额度授权，package-local callable再把业务意图映射为generic PostgreSQL request；Adapter只执行已校验的`query`/`execute`/`snapshot`协议并报告事实。Agent无直连route时，这条路径才构成pre-effect边界。

### Resource and Evaluation Control Flow

```text
operator → `bora run <environment-package> --task <id>`
  → composition + Config load_and_lock
  → validate provider/resource image/platform/action/snapshot declarations
  → L1 Provider prepares Attempt network/workspace
  → EnvironmentManager.prepare
      → create private PostgreSQL container/volume/role
      → run package-declared seed inputs through Adapter
      → bounded healthcheck → resource ready
  → start Harness without DB credential/direct route
  → real Agent returns structured business intent
  → package-local Tool maps intent to action_id + generic operation/payload
  → Environment Capability
      → validate Attempt/resource/state/action/deadline/cancel
      → atomically reserve `environment_actions`
      → Adapter executes PostgreSQL protocol request
      → record authorization/start/outcome + state digest
  → Harness publishes declared artifact and returns
  → close Capability + settle/cancel action writers
  → optional PostgreSQL freeze/getter → fixed snapshot manifest
  → v0.8 clean Evaluator consumes artifact + snapshot → Result
  → teardown role/session/container/network/volume → cleanup evidence
```

Control Plane不import/executepackage Harness/Evaluator模块。Seed、business mapping与evaluator truth留在Task Package；Runtime通过process/Adapter边界调用，PostgreSQL Adapter不得读取task id或action name选择SQL。

### Environment Contract and State

```text
declared
  → preparing
  → ready
  → active
  → freezing
  → frozen
  → tearing_down
  → terminal(cleaned | cleanup_failed)
```

| Surface | Minimum delta | Failure/authority rule |
| --- | --- | --- |
| `EnvironmentResourceDescriptor` | resource id、kind、lifecycle、component image/platform、private network、setup refs、allowed action ids、snapshot strategy | 全部进入lock；unknown kind/ref/action/snapshot在Attempt前失败 |
| `EnvironmentBinding` | Attempt/resource identity、opaque handle、state、deadline、actual image/network/role identity | Harness只持opaque scoped client，无endpoint/credential/admin control |
| `EnvironmentActionRequest` | request id、action id、operation=`query|execute`、validated payload、deadline | package负责business mapping；Adapter不按action id分支 |
| `ActionAuthorization` | Attempt/resource/action、reservation sequence、count_on=`authorized`、decision/reason | Adapter开始前形成；authorized后error/cancel不退款 |
| `EnvironmentActionResult` | typed value/rows、adapter_started、mutation_observed、usage/latency、sanitized error | Agent output先schema验证；DB exception/secret不直出 |
| `EnvironmentSnapshotManifest` | resource、strategy、schema/version、read-only target、digest、created-after-writer-stop | 只供Evaluator materialize；不含live credential/endpoint |
| `EnvironmentOutcome` | prepare/health/actions/freeze/teardown与cleanup warning | Runtime/Evaluation/cleanup事实分栏 |

- `query`只允许Adapter预定义的single-statement readonly execution mode；`execute`允许package提供的validatedstatement/payload，但Runtime仍先按declared action id授权，DB role/transaction/statement timeout形成第二道边界。
- Request id在当前parent/Attempt内防止重复dispatch：相同id+相同payload返回既有terminal result或in-flight handle；相同id+不同payload fail closed。parent crash后不承诺replay恢复，resource必须teardown/禁止复用。
- 并发最后额度由Attempt authority lock原子reserve；计数点为`authorized`。Adapter已开始后即使DB rollback、timeout或cancel也不退款，避免重复外部effect。
- Harness terminal后resource拒绝新action；in-flight action有界settle/cancel。只有相关writer停止后才进入freeze/getter。

### PostgreSQL Adapter Boundary

- Adapter配置只包含image/platform、health、connection policy、role privileges、statement/transaction timeout、generic operation constraints与snapshot strategy；不包含Benchmark、task、role或业务action分支。
- Package `environment/`提供seed input refs；Runtime校验package path并通过Adapter执行，Harness不直接读取admin credential。
- Runtime创建Attempt-localleast-privilege role；Agent/Harness network view不解析resource alias，只有Adapter process/view可达数据库端口。
- Adapter对payload做类型、单statement、parameter binding与size限制；禁止shell拼接、多statement、COPY host path、extension/admin操作，除非未来明确资源合同扩展。
- freeze/getter在writer stop后撤销mutation入口、终止/等待写session并生成canonical snapshot；Evaluator只看snapshot/materialized artifact，不连接live database。

### Failure and Cleanup Semantics

| Condition | Stable kind / point | Mutation/Evaluator | Cleanup |
| --- | --- | --- | --- |
| unknown kind/image/platform/ref/action | `environment_config_invalid`，Config | Attempt前零mutation/零Evaluator | 无resource或清理partial preflight |
| image pull/start/health/seed失败 | `environment_prepare_failed` / `environment_health_timeout` | Harness/Agent零启动 | 逆序关闭session/role/container/network/volume |
| undeclared/closed/cross-Attempt action | `environment_action_denied`，authorization | Adapter start count 0，state digest不变 | resource保持ready/active；run按Harness策略收口 |
| hard ceiling耗尽/duplicate conflict | `environment_action_limit_exceeded` / `environment_request_conflict` | Adapter start count 0 | reservation事实保留；无退款/扩额 |
| Adapter/DB timeout/cancel/error | typed `environment_action_failed` | 可能已开始mutation；transaction outcome与`mutation_observed`显式 | rollback/close session；Harness决定terminal，不能伪装低分 |
| bypass attempt | `network_projection_denied` / `credential_projection_denied` | DB无连接/状态不变 | 关闭违规process/capability并统一cleanup |
| writer/freeze/snapshot失败 | `environment_writer_stop_unconfirmed` / `environment_snapshot_failed` | Evaluator零启动 | teardown仍执行，Result为infrastructure error/no score |
| teardown失败 | `environment_cleanup_failed` warning | 不覆盖已形成score | unknown resource禁止复用；evidence记录owner与manual locator，不泄漏credential |

## Phase 0: PostgreSQL resource、authority、bypass、snapshot 与 teardown probes

### Goal

在建立Environment Manager前，用真实Attempt-local PostgreSQL证明resource lifecycle、pre-effect authority、物理旁路关闭、稳定snapshot与所有主要失败清理可行。

### Tasks

- 构建固定digest/platform的minimal PostgreSQL resource image，运行container/network/volume/least-privilege role、seed、bounded health与normal teardown probe。
- 以真实counter/table mutation验证action allowlist与`environment_actions=1`并发最后额度；denied/第2请求在Adapter start前失败，前后canonical state digest相同。
- 验证request id same/same与same/different语义、authorized后timeout/cancel/no-refund、transaction rollback与mutation outcome分栏。
- 从Harness/Agent view尝试DNS/IP/socket/credential/admin连接，证明v0.8 network/credential投影关闭旁路；Adapter path保持可用。

## Risks and Mitigations

| Risk | Mitigation |
| --- | --- |
| PostgreSQL Adapter演变成Benchmark业务层 | Adapter只处理resource protocol/config；SQL/business mapping留package；第二领域source/trace genericity gate |
| action allowlist在数据库mutation后才检查 | parent pre-effectauthorization与reservation；Adapter start count/state digest negative；denied无DB连接 |
| Agent绕过Environment Capability直连DB | private network、nocredential/noalias、scopedAdapter role；DNS/IP/socket/admin负向 |
| Harness local CallLimit被误写成Runtime hard ceiling | 两层facts分离；Runtime`environment_actions`独立原子reserve；local guard高值不能扩额 |
| duplicate/timeout造成重复外部effect | process-localrequest dedupe、transaction、count-on-authorized/no-refund；crash后resource不复用，durability归v0.12 |
| snapshot与活跃writer竞态 | closeCapability→settle/stopwriters→freeze/getter→digest；失败时Evaluator零启动 |
| Evaluator获得live DB credential/network | 只materialize snapshot manifest到clean evaluator；无endpoint/credential/directroute tests |
| teardown失败遗留数据库或credential | owner registry+逆序幂等cleanup；revoke role/close sessions；unknown state non-reusable warning |
| image/seed依赖手工环境 | pinned digest+repository build script+tracked seed refs+clean setup；env不作source |
| 第二领域只是改task名 | 不同schema/seed/action/artifact/evaluator contract；同Adapter无branch；public realresource run |
| example被误写成真实Benchmark验证 | Research仍open；Phase 4和User Acceptance明确不升级；fixed upstream需另行闭包 |
| 未授权实现、镜像拉取或费用 | Decision Summary保持`B2`；未获授权不启动数据库/Agent、不改production源码 |
