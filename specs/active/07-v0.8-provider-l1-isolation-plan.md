## Background

### Problem

`v0.6`–`v0.7` 的合同基线让真实 Agent、SDK helper、独立 Evaluator 与 Result 在 L0 前台单 Attempt 中连通，但 L0 仍与宿主共享较弱的进程和文件边界。Context filtering、secret redaction、配置中省略 gold 或一个 `writer_stop_confirmed` 布尔值都不能证明 Harness/Agent 物理不可达 evaluator-only material、未投影 credential、未声明 network，也不能证明后台 writer 已停止。

### Current Behavior

- 当前 production Provider 是 L0 local process；Docker kind 仅可作为 Config declaration 被识别，不构成可运行 Provider L1。
- `bora run` 已有简化 writer barrier 与独立 evaluator 子进程，但 evaluator 仍未获得由 Provider 构造的 clean runtime 和单独 materialize 的只读输入视图。
- Roadmap `v0.1`–`v0.7` 的内部工程清单已反映实现事实，Version Index 仍等待用户验收；本 Spec 不回退这些事实，也不把未验收基线写成当前完成态。
- 证据等级仍按仓库当前声明处理；容器存在、单测或 fixture 均不能自动升级为 `isolated`。

### Goals and Non-goals

- Goal: 让同一 production `bora run` 通过 Docker（或实现期经权威对齐的等价 L1 Provider）运行真实 Agent Attempt，并以明确 image digest、platform、mount/path view、network policy、credential projection 与 cleanup facts 形成 `assurance: l1` evidence。
- Goal: Harness 与 Agent runtime 不 mount `evaluation/`、gold 或 evaluator-only material；只有 capability close 且所有 writer 确认停止后，Runtime 才把 `evaluation.inputs` allowlist materialize 到新的 clean evaluator runtime。
- Goal: credential 由 Runtime 从既有接受的 host source 解析，只投影给获准 Executor boundary；credential bytes 不进入 Task Package、Harness 默认环境、workspace、lock、命令参数、日志或 evidence。
- Goal: network default deny；仅锁定 policy 中声明的 destination class 可达。Provider 在 Harness 启动前完成 policy provision 与 property probe，失败即 fail closed。
- Goal: timeout/cancel/error 统一进入 container/process termination、writer confirmation、network/mount teardown 与资源清理；cleanup warning 不覆盖已形成 score，但 writer 未确认时 Evaluator 不启动。
- Non-goal: 本 Spec 不提供 L2 per-actor UID/GID、VM/微虚拟机、跨主机 Provider、Docker socket delegation、镜像供应链全套签名或开放远程镜像市场。
- Non-goal: 本 Spec 不新增第二 AgentExecutor、真实 Environment、Campaign、后台控制、durable/reopen 或恢复 authority；分别由 `v0.9`–`v0.12` 承担。
- Non-goal: 本 Spec 不接入或宣称任何真实 upstream Benchmark；`real-benchmark-verified` 仍需固定 upstream 与 `v0.10` 后的真实 Environment journey。
- Evidence boundary: 技术 gates 通过只形成 L1 工程证据；只有用户复验 success 与全部隔离红线后，才可在限定 example/platform/image 范围声称 `isolated`。

### Key Insight

L1 的完成条件是物理不可达与可观测终止事实同时成立。Provider 必须先构造受限 view，再启动不受信任的 package runtime；Evaluator 必须在 writers 停止后进入另一 runtime。任何仅靠 prompt、配置投影 DTO、路径字符串检查或容器存在性的证明都不足以支撑 `isolated`。

### Runnable Acceptance

- Public entrypoint: `uv run bora run <package> --task <task-id>`，Provider 由 locked `provider.kind=docker` 选择；CLI 不直接调用 Docker SDK 或 import package module。
- Production composition root: `src/bora/application/composition.py`；只在此装配 DockerProvider、credential/network adapters、evidence store 与 evaluator runtime。
- Clean setup: `uv sync --frozen --all-packages`，`docker version`，`docker buildx version`，`uv run python docker/attempt/build.py --platform linux/arm64 --output-lock .bora/runtime-images/provider-l1.json`。
- Success smoke: `uv run bora run examples/provider-l1-agent-eval --task provider-l1-agent-eval`；真实 Codex 在 L1 Attempt 内完成 declared output，barrier 后 clean evaluator 独立 PASS，CLI exit 0，evidence 记录 `assurance: l1`、platform、image digest、view/network/credential policy digests、writer-stop 与 cleanup facts。
- Expected failure — hidden material: `uv run bora run examples/provider-l1-denied --task hidden-material-denied`；Harness 读取 `evaluation/`/gold 或构造 symlink escape 失败，Evaluator 不启动，CLI 非 0，error kind 为 `workspace_view_denied`，cleanup 完成。
- Expected failure — credential/network: `uv run bora run examples/provider-l1-denied --task projection-denied`；Harness/Agent 读取未投影 credential 或访问未声明 endpoint 均在目标 effect 前失败，不泄漏值、不静默扩权、不 fallback，cleanup 完成。
- Writer negative: `uv run bora run examples/provider-l1-denied --task residual-writer`；background writer 在 barrier 被终止并确认，或确认失败时 Evaluator 保持零启动；materialized input 在 evaluator 生命周期内 digest 不变。
- Evaluator isolation negative: `uv run pytest tests/acceptance/test_provider_l1_evaluator_isolation.py -k "no_agent_credential or no_mutable_workspace or no_network or allowlisted_inputs_only" -q`。
- Regression smokes: `uv run bora run examples/agent-eval --task agent-eval`、`uv run bora run examples/evaluator-negative --task evaluator-negative`、`uv run bora run examples/sdk-agent-session --task sdk-agent-session`、`uv run bora run examples/sdk-tool-guard --task sdk-tool-guard`、`uv run bora run examples/sdk-tool-guard-denied --task sdk-tool-guard-denied` 与 `uv run pytest`；既有 L0 path 保持显式 `assurance: l0`，不得静默冒充 L1。
- Observable evidence: run summary、Provider prepare/start/stop/cleanup facts、container/image/platform identity、logical path-view/policy digests、credential projection locator的非敏感标识、writer inventory/confirmation、materialized input digest、clean evaluator identity、raw evaluation、flat Result 与 cleanup warning；禁止记录 secret value、host credential path、Docker socket、raw prompt/reasoning或 evaluator-only bytes。

### Extension Seams

- Provider contract: Runtime 只依赖 prepare/start/stop/cleanup、view/network/credential projection 与 writer-confirm facts；Docker 是首个 L1 implementation，未来等价 sandbox 不改变 Harness API。
- Image resolution: image build/resolve 与 Attempt launch 分开；launch 只接受已锁定 digest/platform，不接受运行中浮动 tag。
- Credential source: host store/locator 与 projection adapter 分开；Task Package 只引用 logical credential grant，不知道宿主路径或 value。
- Network policy: 以 destination/resource class 与 protocol规则工作，不读取 Benchmark、task、role或业务action选择逻辑。
- Evaluator runtime: 只消费 materialization manifest；不 import Harness、Agent Service或Task evaluator到Control Plane，package evaluator仍经独立worker/container入口执行。

### Control Flow

```text
operator → `bora run <l1-package> --task <id>`
  → application composition → Config load_and_lock
  → validate Docker capability + image lock + platform + logical grants
  → Lifecycle creates Run/Trial/Attempt
  → DockerProvider.prepare
      → create Attempt network/policy
      → create workspace volumes and explicit path views
      → bind scoped credential only to Executor boundary
      → start Harness container without evaluator-only mounts
  → Harness worker uses Attempt-bound Capability and Agent Service
  → HarnessTerminal
  → close Capability → stop/kill/confirm every registered writer
      → unconfirmed: evaluation-input failure, zero evaluator start
  → materialize only evaluation.inputs into read-only volume
  → start clean evaluator container without Agent credential/network/mutable workspace
  → validate evaluator raw → bind flat Result
  → teardown evaluator + Attempt containers/network/volumes/projections
  → CLI summary + exit code
```

Control Plane 只解析配置、驱动契约与装配 Adapter；不得 import/execute package `harness.py` 或 `evaluator.py` 作为 Python 模块。Task code 只在 Provider 创建的 worker/evaluator runtime 内加载。

### Visibility and Data Flow

| Data/capability | Source → consumer | L1 rule |
| --- | --- | --- |
| image/platform lock | repository build input → Config/Provider | digest + platform 在 Attempt 前固定；浮动 tag、缺失 digest、platform mismatch fail closed |
| package/Harness files | package store → Harness path view | 只读 allowlist；`evaluation/`、gold、host root 与Docker socket absent |
| mutable workspace | Provider volume → Harness/Agent declared views | 仅声明 write path 可写；跨 view、read-only、symlink/traversal拒绝 |
| Agent credential | accepted host source → parent/Executor-only projection | Harness默认env/workspace不可见；value不序列化、不落证据 |
| network | locked policy → Attempt network | default deny；只允许声明 destination class；无direct-IP/DNS/redirect旁路 |
| published Artifact | Harness capability → writer registry/staging | logical name + producer/path检查；未publish或writer未停不materialize |
| evaluator-only material | package store → clean evaluator volume | barrier后按`evaluation.inputs`复制；从未mount到Harness/Agent |
| evaluator raw/Result | evaluator worker → binder/evidence/CLI | raw独立校验；score、runtime error与cleanup warning分栏 |

### Reference Data Structures

- `ProviderImageLock`: `kind`、`platform`、`image_digest`、build-input digest、runtime ABI 与生成器版本；不含host绝对路径或registry credential。
- `L1WorkspacePlan`: Attempt root、named `WorkspaceView`、每个view的read/write/absent logical paths、mount mode与canonical package-relative source；拒绝overlap升级、symlink escape与隐式root mount。
- `NetworkProjection`: default action、允许的destination/protocol/port class、policy digest与probe outcome；不保存DNS credential或未脱敏endpoint secret。
- `CredentialProjection`: logical grant id、consumer=`executor`、delivery mode、redacted source kind与lifetime；无secret value、host path或可复用token。
- `WriterRecord`: Attempt、container/process identity、kind、start/terminal/kill/confirm timestamps、final status；所有materialization输入绑定confirmation与digest。
- `EvaluationMaterializationManifest`: 只列logical input、source artifact/package locator、read-only target、digest与evaluator runtime id；不把hidden bytes复制进Control Plane evidence。
- `ProviderL1Outcome`: prepare/start/stop/cleanup、actual assurance、image/platform、policy digests、writer confirmation、resource cleanup与sanitized error/warning facts。

### Failure and Cleanup Semantics

| Condition | Failure point and stable kind | Evaluator | Cleanup/result rule |
| --- | --- | --- | --- |
| Docker daemon/buildx/image/platform不可用 | preflight/prepare：`provider_l1_unavailable` / `image_unresolved` / `platform_mismatch` | 不启动 | 不启动Harness；清理已创建probe/Attempt资源，无伪L1 |
| path view/mount/symlink无效 | prepare或访问边界：`workspace_view_invalid` / `workspace_view_denied` | 不启动或保持未启动 | mutation前拒绝；清理container/volume；不扩大mount补救 |
| credential缺失/越权/泄漏scan命中 | preflight/invocation：`credential_projection_unavailable` / `credential_projection_denied` / `credential_leak_detected` | 不启动 | 停止Executor/Harness；revoke projection；保留sanitized failure，不输出value |
| 未声明network destination | pre-effect：`network_projection_denied` | 不启动 | 连接失败且无fallback；清理network/rules |
| Harness timeout/cancel/crash | run：既有Runtime terminal kind | 仅writer确认且input完整时按既有策略；否则不启动 | TERM→wait→KILL→confirm；统一teardown |
| writer无法确认停止 | sealing：`writer_stop_unconfirmed` | 零启动 | Result为infrastructure error/no score；cleanup warning可附加，资源禁止复用 |
| materialization缺失/越界/digest变化 | evaluation-input：`evaluation_input_invalid` | 零启动 | 删除staging/evaluator volume；保留Runtime/Harness事实 |
| evaluator crash/malformed raw | evaluation：既有typed error | 已启动且失败 | 无score或合法error；cleanup仍执行 |
| cleanup失败 | cleanup：sanitized warning | 不重跑/不改已形成score | `cleanup_warning`单列；状态不明资源禁止复用并在evidence中可定位 |

## Phase 0: L1 image/platform 与六项最高风险隔离 probes

### Goal

## Risks and Mitigations

| Risk | Mitigation |
| --- | --- |
| Docker容器存在被误写成完整隔离 | 六项property-level real probes；actual assurance进入evidence；缺一项即不升级`isolated` |
| macOS bind mount/symlink语义造成hidden path旁路 | 容器内真实negative覆盖read-only、absent、symlink、traversal与host path；不只测Python path normalization |
| dynamic provider endpoint让network allowlist不可用或可旁路 | Phase 0先验证DNS/IP/redirect模型；机制不闭合则路由Research并停止，不放宽为全网 |
| credential被投影到整个Harness容器或落盘 | parent解析、Executor-only最小delivery、Harness默认env allowlist、全树byte scan与ephemeral cleanup |
| 主进程退出被误认为writer已停 | writer registry覆盖child/background process；TERM→wait→KILL→confirm；unconfirmed阻止Evaluator |
| clean evaluator仍复用Agent volume/network/secret | 新container+新read-onlyvolume；显式absent capability tests；materialization manifest是唯一输入 |
| cleanup失败覆盖有效score或遗留资源被复用 | score先独立bind；warning分栏；unknown resource state禁止复用并可定位 |
| L1负向example渗入production authority | example仅经public package boundary运行；production不import tests/example modules；architecture scan |
| 旧L0路径被静默删除或冒充L1 | regression保留显式`assurance:l0`；默认变更需另行权威同步，不在本Spec暗改 |
| v0.8被误写成真实Benchmark验证 | scope只含仓库回归package；fixed upstream、真实Environment与用户验收由v0.10+Research承担 |
| Adapter出现Benchmark/task分支 | 命名与测试仅依据docker、network、credential、filesystem/evaluator机制；generic contract tests不读取task identity |
| 未授权实现或外部副作用 | Decision Summary保持`B2`；未获实现授权不运行Docker、真实Codex或修改production源码 |
